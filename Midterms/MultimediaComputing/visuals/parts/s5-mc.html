Question 1 · Lecture 2, Wavelength and period

A 170 Hz tone travels through air at 340 m/s. What is its wavelength?

  1. a 0.5 m No. 170 / 340 = 0.5 is f/v, the upside-down formula.
  2. b 2 m Correct. λ = v/f = 340/170 = 2 m.
  3. c 57,800 m No. 340 × 170 = 57,800 is v × f.
  4. d 5.88 ms No. 1/170 s = 5.88 ms is the period T. It is a time, and a wavelength is a length.

Answer: b. Wavelength is the distance one cycle occupies in space. In one period T the wave moves v × T, so the slide formula is λ = vT. With T = 1/f this gives λ = v/f = 340 / 170 = 2 m.

Why the other options are wrong

Option a
0.5 is f/v

Dividing the wrong way round gives cycles per metre, the inverse of λ.

170 / 340 = 0.5 unit: (1/s) / (m/s) = 1/m
Option c
57,800 is v × f

Multiplying gives the wrong unit, so it cannot be a distance.

340 × 170 = 57,800 unit: (m/s) × (1/s) = m/s²
Option d
5.88 ms is the period

The answer is in seconds. The question asks for a length in metres.

T = 1/170 s = 5.88 ms λ = v × T = 340 × 0.00588 = 2 m
Exam line

Wavelength is the distance occupied by one cycle, the distance a signal travels in one period: λ = vT = v/f, in meters. Period T = 1/f is a time.

Question 2 · Lecture 3, MIDI bytes

In MIDI, the value of a status byte lies in the range:

  1. a 0 to 127 No. That is the range of a data byte, whose MSB is 0.
  2. b 0 to 15 No. That is the range of the channel nibble, the four low bits of a status byte.
  3. c 128 to 255 Correct. A status byte has its MSB set to 1, so it is at least 1000 0000 = 128.
  4. d 0 to 255 No. That is every possible 8-bit value, data bytes included.

Answer: c. The slide says "The data in a MIDI status byte is between 128 and 255; each of the data bytes is between 0 and 127." The reason is the most significant bit. A status byte has MSB = 1, which alone is worth 128, and a data byte has MSB = 0, which caps it at 127.

Inside a status byte, the three bits after the MSB hold the message type and the four low bits hold the channel, one of 16 (0 to 15).

Exam line

"The data in a MIDI status byte is between 128 and 255; each of the data bytes is between 0 and 127." Status byte: MSB = 1, three bits of message, four low bits = channel.

Question 3 · Lecture 4, Shannon-Fano and Huffman coding

Which statement about Shannon-Fano and Huffman coding is correct?

  1. a Shannon-Fano is top-down (sort, then recursively split into two parts with about equal counts); Huffman is bottom-up (repeatedly merge the two least probable nodes) Correct. These are the slide titles: "a top-down approach" and "a bottom-up approach".
  2. b Shannon-Fano is bottom-up (merge the two least probable nodes); Huffman is top-down (recursively split the sorted list) No. It swaps the two algorithms.
  3. c Both are top-down; they differ only in which branch gets 0 and which gets 1 No. Huffman starts at the leaves and builds upward to the root.
  4. d Both build a dictionary of variable-length strings and send fixed-length codes No. That describes LZW. Both of these send variable-length codes for single symbols.

Answer: a. Shannon-Fano starts with the whole sorted list at the root and splits it into two parts with about the same count, again and again, until each part holds one symbol. Huffman starts with the symbols as leaves and merges the two least probable nodes into a parent, again and again, until one root is left.

For HELLO both happen to give the same codes (L 0, H 10, E 110, O 111, 10 bits in total). The trees are built in opposite directions.

Exam line

"Shannon-Fano Algorithm, a top-down approach": sort, then recursively divide into two parts with about the same counts. "Huffman Coding Algorithm, a bottom-up approach": repeatedly merge the two lowest counts into a parent.

Question 4 · Lecture 5, MPEG-1 audio layers

On the MPEG-1 Audio encoding characteristics slide, which bit-rate range and target belong to Layer 3 (MP3)?

  1. a 32-448 kbps, target 192 kbps No. That is Layer 1.
  2. b 32-384 kbps, target 128 kbps No. That is Layer 2 (MP2).
  3. c 32-320 kbps, target 64 kbps Correct. "Layer 3: 32-320 kbps, target 64 kbps".
  4. d 32-320 kbps, target 320 kbps No. The range is right, but 320 kbps is the top of the range. The target is 64 kbps.

Answer: c. Slide 23 lists the three layers. Each higher layer is more complex and removes more redundancy, so it needs fewer bits for the same quality. The target falls from 192 to 128 to 64 kbps, and the top of the range falls from 448 to 384 to 320 kbps.

Slide 25 gives MP3 a goal of 128 kbps. That figure is for stereo, 64 kbps per channel.

Exam line

Question 5 · Lecture 6, Image resampling and interpolation

Which image interpolation method gives the sharpest images and preserves fine details, but is slow?

  1. a Nearest neighbor No. Nearest neighbor is "fast and simple" with "loss of sharpness" and checkerboard artifacts.
  2. b Bilinear No. Bilinear averages only the 2×2 nearest pixels, which softens edges and flattens peaks.
  3. c All three methods give the same sharpness; they differ only in speed No. Figure 1 shows three visibly different results from the same input.
  4. d Bicubic Correct. Slide 36: "Images are sharpest; fine details are preserved; slow".

Answer: d. Bicubic interpolation fits a cubic curve through the 4×4 = 16 nearest pixels, so it follows the shape of the signal between samples. It costs 16 reads per output pixel against 4 for bilinear and 1 for nearest neighbor, which is why it is slow.

Exam line

Bicubic: "Images are sharpest; fine details are preserved; slow". Nearest neighbor: "Fast and simple; loss of sharpness; artifacts (checkerboard)". Resample when rescaling, after a geometric transformation, or when output coordinates are not discrete.

Question 6 · Lecture 7, Neighbors of a pixel

How many pixels are in N4(p) for p = (3, 5), and which are they?

  1. a 4: (2,5), (4,5), (3,4), (3,6) Correct. (x±1, y) and (x, y±1): up, down, left and right of p.
  2. b 4: (2,4), (2,6), (4,4), (4,6) No. These are the diagonal neighbors ND(p).
  3. c 8: every pixel with D8 = 1 from p No. That is N8(p) = N4(p) ∪ ND(p).
  4. d 4: (1,5), (5,5), (3,3), (3,7) No. These are two steps away from p (D4 = 2).

Answer: a. N4(p) for p = (x, y) is (x+1, y), (x−1, y), (x, y+1), (x, y−1). With x = 3 and y = 5 that gives (4,5), (2,5), (3,6), (3,4), four pixels. Here x is the row and y is the column.

Exam line

N4(p) = (x+1,y), (x−1,y), (x,y+1), (x,y−1). ND(p) = the four diagonal pixels. N8(p) = N4(p) ∪ ND(p).

Question 7 · Lecture 9, Logic operations

Which statement about the XOR operation on images is correct?

  1. a XOR sets bits that are the same in both operands to 1 and bits that differ to 0 No. It is the reverse: equal bits give 0, different bits give 1.
  2. b p XOR v = 0 exactly when p = v, so XOR with v turns every pixel of value v black; it is used to find all pixels of a certain value Correct. "XOR operation sets the pixels that are specified to black, others to nonblack."
  3. c XOR with 255 gives the same result as adding 255 with clamping No. p XOR 255 flips every bit, which is NOT: 255 − p. Adding 255 and clamping gives 255 for every p.
  4. d XOR is used to adjust the contrast of an image, like multiplication No. Contrast is changed by multiplication, an arithmetic operation.

Answer: b. XOR works bit by bit: equal bits give 0 and different bits give 1. The result is 0 only when all eight bit pairs are equal, that is when p = v. So XOR with v makes exactly the pixels of value v black, and every other pixel stays nonblack.

Exam line

XOR sets equal bits to 0 and different bits to 1. "In image processing, XOR operation sets the pixels that are specified to black, others to nonblack." Uses: find all pixels of a certain value, draw the mouse cursor, special effects.

Question 8 · Lecture 10, Hit-or-miss transform

The hit-or-miss transform A ⊛ B = (A ⊖ X) ∩ [A^c ⊖ (W − X)] gives:

  1. a the boundary of A, that is A − (A ⊖ B) No. That is boundary extraction.
  2. b A with all its holes filled No. That is region filling, an iteration of dilations limited by Aᶜ.
  3. c the erosion of A followed by a dilation No. That is opening.
  4. d the points where the shape X fits in A and, at the same time, its local background W − X fits in A^c Correct. B₁ = X must hit A and B₂ = W − X must hit Aᶜ at the same point.

Answer: d. The first erosion A ⊖ X marks every point where X fits inside the foreground, which includes points inside larger shapes. The second erosion Aᶜ ⊖ (W − X) marks every point where the ring of background around X fits in the background. Only the location of an exact copy of X passes both tests.

Why the other options are wrong

Option a
Boundary extraction

Erode A by B and subtract the result from A. One erosion, one set difference, no second structuring element.

β(A) = A − (A ⊖ B)
Option b
Region filling

Start from a point inside a hole and dilate, keeping only pixels of Aᶜ, until nothing changes.

Xk = (Xk−1 ⊕ B) ∩ Aᶜ
Option c
Opening

Erosion followed by dilation with the same B. It removes thin parts and small objects.

A ∘ B = (A ⊖ B) ⊕ B
Exam line

A ⊛ B = (A ⊖ X) ∩ [Aᶜ ⊖ (W − X)] with B = (X, W − X). It is "the set of points at which, simultaneously, B₁ found a match ('hit') in A and B₂ found a match in Aᶜ".

Question 9 · Lecture 11, Second order operators

Which is a disadvantage of the Laplacian edge detector?

  1. a It is sensitive to noise, produces double edges and cannot detect edge direction Correct. These are the three disadvantages on slide 45.
  2. b It needs eight masks, one for each orientation No. That describes the compass gradient operators. The Laplacian is one mask.
  3. c It has no zero crossing, so edges cannot be localized No. The Laplacian changes sign at an edge, and this zero crossing gives better edge localization.
  4. d It is a first order operator, so it gives one thick spike per edge No. The Laplacian is second order. One spike per edge is what a first derivative gives.

Answer: a. Slide 45 lists the Laplacian's disadvantages: "Typically unacceptably sensitive to noise", "Produce double edges", "Unable to detect edge direction". A second derivative takes differences of differences, so it boosts noise more than a first derivative. It answers one edge with a positive and a negative lobe, and it returns one number per pixel with no direction.

Exam line

Laplacian: "better edge localization", a sign change at image edges, the zero crossing. Disadvantages: "sensitive to noise", "produce double edges", "unable to detect edge direction".

Question 10 · Lecture 12, Nearest neighbor classification

How does a nearest neighbor classifier assign a class to a feature vector?

  1. a It computes the mean of each class and chooses the closest mean, rejecting the vector if it is too far No. That is the nearest class mean classifier (slide 38).
  2. b It groups the unlabeled samples into natural clusters No. That is unsupervised learning (clustering). NN needs labelled training samples.
  3. c It keeps all training samples, finds the training sample closest to the feature vector and assigns that sample's class; it can be extended to k nearest neighbors Correct. This is slide 41 almost word for word.
  4. d It converts the pattern into a grammar and parses it No. That is structural pattern recognition.

Answer: c. Slide 41: "Keep all the training samples in some efficient look-up structure. Find the nearest neighbor of the feature vector to be classified and assign the class of the neighbor. Can be extended to K nearest neighbors." With k neighbors the majority class wins.

Nearest class mean keeps one vector per class. It fails when a class has two modes, because its mean then lies between them (slide 39).

Exam line

Nearest neighbor: "Keep all the training samples ... find the nearest neighbor of the feature vector ... assign the class of the neighbor. Can be extended to K nearest neighbors." Nearest class mean keeps only one mean per class.
