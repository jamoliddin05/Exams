Question 1 · 10 pts · Lecture 10, Morphology

Morphology: dilation, erosion and boundary extraction

Binary image A (6 x 6, 1 = foreground, pixels outside the image count as 0) and the structuring elements B1 (1 x 3) and B2 (3 x 3). The outlined cell is the origin.

  1. (a)What are dilation and erosion? Give the set definition of each and what it does to the foreground. (4 pts)
  2. (b)Compute A ⊕ B1 and A ⊖ B1. Then extract the boundary β(A) = A − (A ⊖ B2). (6 pts)

(a) What to write

  • Morphology is a collection of non-linear operations related to the shape of features in an image. The structuring element B is a small binary matrix with an origin.
  • Dilation: A ⊕ B = { z | (B̂)z ∩ A ≠ ∅ }, the set of all displacements z such that the reflected B and A overlap by at least one element. Each pixel takes the maximum over the neighbourhood. It enlarges bright regions, shrinks dark regions, expands the boundary and joins broken segments.
  • Erosion: A ⊖ B = { z | (B)z ⊆ A }, the set of all points z such that B translated by z is contained in A. Each pixel takes the minimum. Foreground areas shrink, holes become larger, and objects smaller than B disappear.
  • Duality: (A ⊖ B)ᶜ = Aᶜ ⊕ B̂.

(b) Worked solution

  • B1 is symmetric, so B̂1 = B1. Pixels outside the image count as 0. Coordinates are (row, col), 0-based, with (0,0) at the top left.
  • A ⊕ B1: the output is 1 if the pixel or its left or right neighbour is 1. Each horizontal run grows by 1 pixel at each end.
  • A ⊖ B1: the output is 1 only if the pixel and both horizontal neighbours are 1. Each run loses its two end pixels.
  • A ⊖ B2: the output is 1 only if the whole 3x3 neighbourhood is 1.
  • Dilation fills the gap at (2,4), so the isolated pixel (2,5) joins the block. Rows 0 and 5 stay 0 because B1 is horizontal only.
  • Erosion deletes the isolated pixel (2,5). It also deletes (3,0), because its left neighbour is outside the image (= 0).
  • A ⊖ B2: (2,1) fails because (1,0) = 0, (2,3) fails because (1,4) = 0, (3,1) fails because (2,0) = 0, and (3,3) fails because (2,4) = 0. Only (2,2) and (3,2) survive.

Result: A ⊕ B1 = 22 pixels, A ⊖ B1 = {(1,2), (2,2), (3,1), (3,2), (4,2), (4,3)}, and β(A) = A without (2,2) and (3,2), which is 13 pixels.

Exam line

Dilation A ⊕ B = { z | (B̂)z ∩ A ≠ ∅ } is a local maximum and grows the foreground. Erosion A ⊖ B = { z | (B)z ⊆ A } is a local minimum and shrinks it. Boundary extraction: β(A) = A − (A ⊖ B).

Question 2 · 10 pts · Lecture 11, Spatial filtering

Filtering: high boost and median vs average

  1. (a)Write the high-boost (unsharp masking) formula and the 3x3 high-boost mask for α = 1.5. What is the result when α = 1, and what happens when α > 1? (4 pts)
  2. (b)
    One image row with a step edge and one impulse (salt) pixel, positions p0 to p9:
    Apply a 3-point average filter and a 3-point median filter to p1 to p8 (p0 and p9 are kept unchanged). (4 pts)
  3. (c)Which filter removes the impulse and keeps the edge sharp? Explain in one line. Would a min filter or a max filter remove this impulse? (2 pts)

(a) What to write

  • Unsharp masking: "subtract a lowpass filtered image from its original" (another method of highpass filtering).
  • High boost = α · Original − Lowpass. The mask has centre ω/9 and all 8 neighbours −1/9, with ω = 9α − 1.
  • For α = 1.5, ω = 9(1.5) − 1 = 12.5. The centre is 12.5/9 = 1.389, and the mask sums to (ω − 8)/9 = α − 1 = 0.5.
         -1    -1    -1
1/9  x   -1   12.5   -1
         -1    -1    -1
  • α = 1: ω = 8, so the result is the high pass filter (1/9)[−1 −1 −1; −1 8 −1; −1 −1 −1]. It sums to 0, so flat areas become 0 and only the detail remains.
  • α > 1: it restores the low frequency component and retains more of the original background. As α increases, the image gets lighter and looks more like the original, with edge enhancement.

(b) Worked solution

Border rule: p0 and p9 have no full window, so they are kept as they are (start at the first position where the window fits).

Average: 30 30 100 100 100 50 70 90 90 90
Median:  30 30  30  30  30 30 90 90 90 90

(c) What to write

  • The median filter wins. The single 240 is never the middle value of 3, so it disappears, and the step 30 → 90 stays sharp between p5 and p6. The average smears the impulse into three pixels (100) and blurs the edge into a ramp 30, 50, 70, 90. The median is "superior to lowpass filter when dealing with edges". The lowpass filter suits Gaussian noise, not impulse noise.
  • The min filter "removes white spikes". Its output is 30 30 30 30 30 30 30 90 90 90, so the 240 is gone, but the edge moves one pixel right (p6 = 30) and intensity drops. The max filter removes dark spikes. Here it spreads the salt to 30 30 240 240 240 90 90 90 90 90. So the min filter removes this impulse and the max filter does not.
Exam line

High boost = α · Original − Lowpass. α = 1 gives the high pass filter, α > 1 restores the low frequency component. The median filter removes impulse noise and is superior to the lowpass filter at edges. The min filter removes white spikes, the max filter removes dark spikes.

Question 3 · 10 pts · Lecture 9, Histogram equalization

Histogram equalization and lookup table

A 4 x 4 image with 8 gray levels (3 bits, levels 0 to 7):

  1. (a)Calculate the histogram, the normalized sum and the equalized level sk for all 8 gray levels. Show the full table. (5 pts)
  2. (b)Write the equalized image and its histogram. Is the output histogram flat? Why? (2 pts)
  3. (c)A 3-bit lookup table is given below. Apply it to the pixel row 2 7 4 0 5 3 6 1, and say what kind of point transformation this LUT performs. (3 pts)

(a) Worked solution

The steps are: 1) compute the histogram, 2) calculate the normalized sum of the histogram, 3) transform the input image to the output image. The convention follows the slide: L = 8 and N² = 16, so the normalized sum is the running sum × (L−1)/N² = × 7/16, rounded to the nearest integer.

Mapping (LUT): 0 0 0 0 0 3 6 7, that is 4 → 0, 5 → 3, 6 → 6, 7 → 7.

(b) Equalized image

3 3 6 6
0 3 6 7
3 6 6 7
3 3 6 6
  • Output histogram: n0 = 1, n3 = 6, n6 = 7, n7 = 2 (all other levels 0). It is not flat.
  • Why: the discrete approximation. All pixels with the same level map together, so equalization cannot split a level. It only moves levels apart. The narrow bright range 4-7 (a washed-out image) is spread over 0-7. Contrast is stretched near the histogram maxima: levels 5 and 6 were 1 apart and are now 3 apart.

(c) Lookup table

Use each pixel value as the array index, and the new value is the element at that index.

Output row: 1 7 4 0 6 2 7 1. The LUT is an S-shaped contrast stretching around m = 4. Levels below 4 get darker (2 → 1, 3 → 2) and levels above 4 get brighter (5 → 6, 6 → 7), so contrast is increased.

Exam line

Equalization: compute the histogram, calculate the normalized sum (running sum × (L−1)/N²), round, and transform the image. The output histogram is not flat because the levels are discrete. A LUT uses the pixel value as the array index.

Question 4 · 10 pts · Lecture 12, Pattern recognition

Pattern recognition

  1. (a)Draw the flow chart of a pattern recognition system from input to decision, including the side inputs. State the job of each stage in a few words. (5 pts)
  2. (b)Fish example (sorting salmon and sea bass on a conveyor). Why is length alone a poor feature? What do lightness and width add? What is a decision boundary, and why would we move it because of cost? (2 pts)
  3. (c)
    Training samples with feature vector x = [lightness, width]:
    Classify the new fish x = [5, 18] with the nearest neighbor rule (k = 1) and with k-NN, k = 3, using the Euclidean distance. (3 pts)

(a) Flow chart

  • Sensing: "use of a transducer (camera or microphone)". The system depends on the bandwidth, resolution, sensitivity and distortion of the transducer.
  • Segmentation and grouping: "patterns should be well separated and should not overlap" (isolate each fish from the others and from the background).
  • Feature extraction: "discriminative features"; "invariant features with respect to translation, rotation and scale". It reduces the data by measuring certain features.
  • Classification: "use a feature vector provided by a feature extractor to assign the object to a category".
  • Post-processing: "exploit context input dependent information other than from the target pattern itself to improve performance". Costs and context come in here.

(b) What to write

  • Length: the salmon and sea bass length histograms overlap heavily, so any threshold l* misclassifies many fish. "The length is a poor feature alone!"
  • Lightness separates the classes much better (threshold x*). Width adds a second feature: xᵀ = [x₁, x₂] = [lightness, width]. In this 2D feature space a straight line separates the classes better than any single feature.
  • Decision boundary: the border in feature space that splits it into class regions (a threshold for 1 feature, a line or curve for 2).
  • Cost: the two errors do not cost the same, so we "move our decision boundary toward smaller values of lightness in order to minimize the cost (reduce the number of sea bass that are classified salmon!)". This is the task of decision theory. A boundary that is perfect on the training data can still fail on novel input (the issue of generalization).

(c) Worked solution

The query is x = [5, 18], and d = √((Δlightness)² + (Δwidth)²). Both axes below use the same scale, so the circles are true distances.

  • k = 1: the nearest sample is B1, so x is classified as sea bass.
  • k = 3: the nearest samples are B1, S2 and S1, which gives 2 salmon votes to 1 sea bass, so x is classified as salmon.
  • The two rules disagree. 1-NN follows a single (possibly noisy) closest sample, while k-NN takes a majority vote.
Exam line

input → sensing → segmentation → feature extraction → classification → post-processing → decision. Costs and adjustments for context enter at post-processing, adjustments for context and for missing features at classification. 1-NN takes the class of the nearest sample, k-NN the majority of the k nearest.

Question 5 · 10 pts · Lectures 4 and 5, Compression

Compression: entropy, DPCM and compression ratio

  1. (a)
    A source emits five symbols with these probabilities:
    Compute the entropy. Why can no lossless code have an average length below it? (3 pts)
  2. (b)Samples f1 to f6 = 60, 63, 67, 67, 64, 71. (4 pts)
    (i) Simple difference coding: the first sample is sent as is, then dn = fn − fn−1. What is sent? Show that the decoder rebuilds f exactly.
    (ii) DPCM: the prediction is the previous reconstructed sample, f̂n = f̃n−1, with f̃1 = f1 = 60. The prediction error en = fn − f̂n is quantized to the nearest multiple of 4. For n = 2 to 6 give en, the quantized error, the reconstructed sample f̃n and the reconstruction error fn − f̃n.
  3. (c)A 512 x 512, 8-bit gray image is saved as PNG (131,072 bytes) and as JPEG (16,384 bytes). Compute both compression ratios. Which file is lossy and which is lossless, and why can JPEG go below the entropy limit while PNG cannot? (3 pts)

(a) Entropy: η = Σ pi log₂(1/pi)

  • η = 1.875 bits/symbol. A fixed-length code needs 3 bits for 5 symbols.
  • Why no lossless code can beat it: log₂(1/pi) is the self-information of si, the number of bits needed to encode si. The entropy is the average of it, so it is the lower bound on the average code length: η ≤ l̄ (Huffman: η ≤ l̄ < η + 1). A lossless code must keep all the information, so it cannot use fewer bits on average. Here Huffman lengths 1, 2, 3, 4, 4 reach exactly 1.875, because every p is a power of 1/2.

(b)(i) Difference coding

Sent: 60, 3, 4, 0, −3, 7. The decoder adds each difference to the previous value.

This is exactly f, so the coding is lossless. The differences cluster around 0, so they need fewer bits.

(b)(ii) DPCM

The formulas are f̂n = f̃n−1, en = fn − f̂n, ẽn = 4 · round(en/4) and f̃n = f̂n + ẽn. No en is exactly halfway between two multiples of 4, so there are no rounding ties.

Reconstructed: 60, 64, 68, 68, 64, 72. DPCM is lossy, but each error is at most half a step (2). The predictor uses reconstructed values, because the decoder only has those, so the errors do not accumulate. The reconstruction error equals the quantization error en − ẽn.

(c) Compression ratios

B0 = 512 × 512 × 8 = 2,097,152 bits = 262,144 bytes
PNG:  262,144 / 131,072 = 2.0    (4 bits/pixel)
JPEG: 262,144 / 16,384  = 16.0   (0.5 bits/pixel)
  • PNG: 262,144 / 131,072 = 2.0 (4 bits/pixel). PNG is lossless: the decompressed image equals the original exactly.
  • JPEG: 262,144 / 16,384 = 16.0 (0.5 bits/pixel). JPEG is lossy: the result is a close approximation of the original.
  • A lossless coder is bounded by the entropy (rate distortion: R(D) = H at D = 0). A lossy coder accepts distortion D > 0, and quantization (the main source of loss) throws information away, so R(D) < H. That gives a much higher compression ratio.
Exam line

η = Σ pi log₂(1/pi) is the lower bound on the average code length of a lossless code (η ≤ l̄ < η + 1 for Huffman). DPCM predicts from the reconstructed samples and sends the quantized prediction error. Compression ratio = B0/B1.

Question 6 · 10 pts · Lecture 2, Sound and sampling

Sound and sampling

A signal x(t) = 5 sin(2π·250t + π/2) volts.

  1. (a)Give its peak amplitude, frequency, period and phase (in degrees and as a time shift). Find its wavelength in air if the speed of sound is 340 m/s. (4 pts)
  2. (b)A second tone 2 sin(2π·3000t) is added. What is the Nyquist sampling frequency for the mix? If the mix is sampled at fs = 4 kHz, at what frequency does each tone appear after reconstruction? (3 pts)
  3. (c)A 5 s stereo recording is made at 48 kHz with 16 bits per sample. Compute the bit rate and the file size in bytes. The sample rate is then halved: give the new highest frequency that can be captured and the new file size. (3 pts)

(a) Read off A sin(2πft + φ)

  • Peak amplitude A = 5 V (the maximum strength of the signal).
  • Frequency f = 250 Hz.
  • Period T = 1/f = 1/250 = 4 ms.
  • Phase φ = π/2 rad = 90°, which is a time shift of T/4 = 4/4 = 1 ms. The wave starts at its peak: x(0) = 5 sin(π/2) = 5 V.
  • Wavelength λ = v/f = vT = 340 × 0.004 = 1.36 m.

(b) Nyquist and aliasing

  • fmax = 3000 Hz, so the Nyquist sampling frequency is 2 × 3000 = 6 kHz: the signal must be sampled at more than 6 kHz.
  • fs = 4 kHz < 6 kHz, so the mix is undersampled.
  • The 250 Hz tone is below fs/2 = 2 kHz, so it appears at 250 Hz (correct).
  • The 3000 Hz tone is above 2 kHz, so it aliases to fs − f = 4000 − 3000 = 1000 Hz. Check: sin(2π·3000·n/4000) = −sin(2π·1000·n/4000) for every n.

(c) Bit rate and file size

Bit rate = fs × bits × channels
48,000 × 16 × 2 = 1,536,000 bit/s   (1.536 Mbps)
Size = 1,536,000 × 5 / 8 = 960,000 bytes

Halved, fs = 24 kHz: the highest frequency is below 12 kHz (it was below 24 kHz), the bit rate is 768,000 bit/s and the size is 480,000 bytes. The 16 bits per sample do not change. Content between 12 and 24 kHz now aliases, unless it is low-pass filtered first.

Exam line

f = 1/T, λ = v/f, and a phase of 90° = π/2 is a shift of T/4. Nyquist: fs > 2 fmax, or the tone aliases (here to fs − f). Bit rate = fs × bits × channels.

Results below 0 become 0, and results above 255 become 255.

p = 172 = 1010 1100 and q = 105 = 0110 1001.

(d) Negative: s = 255 − r

Negative of F: 135 45 / 215 25.

Addition and subtraction change brightness, multiplication and division change contrast. Clamp results to 0..255. NOT = 255 − pixel, XOR gives 1 where the bits differ, and the negative is s = 255 − r.

Question 8 · 10 pts · Lecture 7, Color

Color: dimensions, illuminants, chromaticity and purity

  1. (a)Name and define the three dimensions of color. In the Munsell system, what are the ranges of value and chroma? (3 pts)
  2. (b)What do the CIE standard illuminants A, B, C, D65 and E represent? (2 pts)
  3. (c)A color has tristimulus values X = 95, Y = 94, Z = 61. Compute its chromaticity coordinates x, y and z. (2 pts)
  4. (d)The reference white is W = (0.31, 0.32). The line from W through the color meets the spectral locus at D = (0.51, 0.48), about 580 nm. What is the dominant wavelength of the color? Compute its purity, and say what purity 0 and purity 1 mean. (3 pts)

(a) What to write

  • Hue: what color it is (red, green, yellow, blue). It is the angle around the gray (black-white) axis of the color solid.
  • Saturation (chroma, colorfulness): how strong or pure the color is, from pink to bright red. It is the distance from the gray axis.
  • Value (lightness, brightness): how light or dark the color is (black, gray, white). It is the height on the axis.
  • Munsell (1915), equal perceptual steps: value runs 0 (dark) to 10 (pure white), and chroma runs 0 (neutral) to 20 (saturated). There are 10 principal hues, R, YR, Y, GY, G, BG, B, PB, P, RP, each split into 10.

(b) CIE standard illuminants

  • A: tungsten light
  • B: sunset
  • C: blue sky
  • D65: average daylight
  • E: equal-energy white, x = y = z = 1/3

All of them lie near the blackbody locus.

(c) Chromaticity

x = X/(X+Y+Z),  y = Y/(X+Y+Z),  z = Z/(X+Y+Z)
X + Y + Z = 95 + 94 + 61 = 250
x = 95/250 = 0.380   y = 94/250 = 0.376   z = 61/250 = 0.244
check: 0.380 + 0.376 + 0.244 = 1

x = 0.380, y = 0.376, z = 0.244.

(d) Dominant wavelength and purity

  • Dominant wavelength: the wavelength of the spectral color which, added to the reference white, produces the given color. Follow the ray from W through S to the locus at D: about 580 nm (yellow).
  • Purity = |WS| / |WD|. WS = (0.380 − 0.31, 0.376 − 0.32) = (0.070, 0.056), so |WS| = √(0.0049 + 0.003136) = √0.008036 = 0.0896.
  • WD = (0.51 − 0.31, 0.48 − 0.32) = (0.20, 0.16), so |WD| = √(0.04 + 0.0256) = √0.0656 = 0.2561.
  • Purity = 0.0896 / 0.2561 = 0.35. Check with one coordinate: 0.07/0.20 = 0.35.
  • Purity 0 = the color is the white point (no saturation). Purity 1 = a pure spectral color on the locus. So S is a pale (desaturated) yellow: dominant wavelength ≈ hue, purity ≈ saturation.
Exam line

x = X/(X+Y+Z), y = Y/(X+Y+Z), z = Z/(X+Y+Z). Given a reference white, the dominant wavelength (hue) is where the ray from white through the color meets the locus, and purity = |WS| / |WD| (saturation) runs from 0 at white to 1 on the locus.
