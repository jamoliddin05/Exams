Question 1 · 10 pts · Lecture 10, Morphology

Morphology: erosion

  1. (a)What is erosion? Define the erosion of a binary image A by a structuring element B (set notation or words) and state the duality between erosion and dilation. (5 pts)
  2. (b)Apply erosion on image A using the structuring element B. The origin of B is its centre pixel, marked [1]. Pixels outside the image are 0. (5 pts)

(a) What to write

  • Morphology is "a collection of non-linear operations related to the shape or morphology of features in an image".
  • Erosion "erodes away the boundaries of regions of foreground pixels". Areas of foreground pixels shrink, and holes inside them become larger. Each pixel takes the local minimum over the structuring element (SE) area.
  • Definition: A ⊖ B = { z | (B)z ⊆ A }, "the set of all points z such that B, translated by z, is contained in A". The slide prints (B̂)z, which is the same for a symmetric B.
  • In practice an output pixel is 1 only where the SE fits, which means every 1 of B lies on a 1 of A.
  • Duality: (A ⊖ B)ᶜ = Aᶜ ⊕ B̂. Eroding the object is the same as dilating the background with the reflected SE and then taking the complement.
(A ⊖ B)ᶜ = { z | (B)z ⊆ A }ᶜ
         = { z | (B)z ∩ Aᶜ = ∅ }ᶜ
         = { z | (B)z ∩ Aᶜ ≠ ∅ }
         = Aᶜ ⊕ B̂

(b) Worked solution

  • Rule: (r, c) becomes 1 only if all 9 pixels of the 3 × 3 window centred at (r, c) are 1. Pixels outside the image count as 0.
  • A 0 pixel can never become 1, because the window includes the centre.
  • Row 0, row 6, column 0 and column 6: the window reaches outside the image, so all of them become 0. This removes the top-left 1s and the corner pixel (6,6).

The interior 1-pixels, row by row:

RowPixels that stay 1 (window all 1)Pixels that become 0 (a 0 in the window)
1(1,1): rows 0–2, cols 0–2 all 1(1,2) and (1,3): (0,3) = 0
2(2,2): rows 1–3, cols 1–3 all 1(2,1): (3,0) = 0; (2,3), (2,4): (1,4) = 0
3(3,2), (3,3)(3,1): (3,0) = 0; (3,4), (3,5): (2,5) = 0
4(4,3), (4,4)(4,1): (3,0) = 0; (4,2): (5,1) = 0; (4,5): (3,6) = 0
5none(5,2) to (5,5): row 6 below is 0

Result: 27 ones become 6: (1,1), (2,2), (3,2), (3,3), (4,3), (4,4).

  • The opening removes only what is smaller than B.
Exam line

Erosion: A ⊖ B = { z | (B)z ⊆ A }, "the set of all points z such that B, translated by z, is contained in A". It takes the local minimum, so foreground regions shrink. Duality: (A ⊖ B)ᶜ = Aᶜ ⊕ B̂.

Question 2 · 10 pts · Lecture 11, Spatial filtering

Filtering: sharpening

  1. (a)What does sharpening do to an image? Why does a sharpening mask sum to 1, while a high-pass mask sums to 0? (4 pts)
  2. (b)For the 8-bit image f below, apply the Laplacian mask L and the sharpening mask S at the pixel in row 2, column 2 (rows and columns are counted from 0; the pixel value is 180). Clip each result to 0..255. (6 pts)

(a) What to write

  • "Sharpening has the opposite affect of blurring." It is also called crispening. It "emphasizes the details in an image" and increases its contrast.
  • The sharpening mask [0 −1 0; −1 5 −1; 0 −1 0] sums to 1. In a flat area the output equals the input, so brightness is kept and only the details (edges) are boosted. It equals identity + Laplacian.
  • The high-pass mask (1/9) × [−1 −1 −1; −1 8 −1; −1 −1 −1] sums to 0, so a flat area becomes 0. It "removes the low frequency components and shows only high detail". The result is a black image with bright edges.
  • Example: a flat area of 90 gives 90 with the sharpening mask and 0 with the high-pass (or Laplacian) mask.

flat area of value v:   output = v × (sum of the mask)  →  sum 1 keeps v, sum 0 gives 0

(b) Worked solution

window around (2,2):    90  140   70
                       120  180  150
                        60  130  200

4-neighbours: 140 + 120 + 150 + 130 = 540     (corners × 0)
L = 4 × 180 − 540 = 720 − 540 = 180     inside 0..255  → 180
S = 5 × 180 − 540 = 900 − 540 = 360     clip           → 255
check: S = f + L = 180 + 180 = 360 → 255

Result: L = 180, S = 360 clipped to 255.

Exam line

Sharpening (crispening) "emphasizes the details in an image" and increases contrast. A sharpening mask sums to 1, so flat areas keep their value. A high-pass or Laplacian mask sums to 0, so flat areas become 0. Sharpening = original + Laplacian, then clip to 0..255.

Histogram equalization

A 3-bit image (L = 8 gray levels) of size 8x8 (64 pixels) has this histogram:

  1. (a)Equalize the histogram. Give the full table: rk, nk, cumulative sum, normalized (scaled) sum, and the new level sk. (7 pts)
  2. (b)Give the histogram of the equalized image. Is it flat? Explain why or why not. (3 pts)

(a) Worked solution

  • Steps: 1. compute the histogram; 2. calculate the normalized sum of the histogram; 3. transform input to output with a LUT.
  • Rule with the slide convention, L − 1 = 7 and MN = 64 pixels. Round to the nearest integer, as on slides 30-31 where 4.81 becomes 5.

sk = round( (L − 1) / MN × Σj=0..k nj ) = round( 7 / 64 × cumulative sum )

Result: LUT 0→1, 1→2, 2→4, 3→5, 4→6, 5→7, 6→7, 7→7.

(b) New histogram

  • Add the nk that map to the same sk. Level 7 collects 5 + 3 + 1 = 9 pixels. The total is still 64.
  • Not flat: levels 5, 6, 7 merge into 7, and levels 0 and 3 stay empty.
  • Why: in the discrete case H.E. moves whole levels and cannot split one level into several. "The resulting histogram is not flat" (slide 26).
  • It still spreads the dark image (most pixels at 0-3) over the range 1-7, so contrast improves. The mean level goes from 2.47 to 4.08.
Exam line

Compute the histogram, the normalized sum and the LUT, sk = round((L − 1)/MN × cumulative sum). In the discrete case "the resulting histogram is not flat", because whole levels move and merge, but the contrast improves.

Question 4 · 10 pts · Lecture 12, Pattern recognition

Pattern recognition: design cycle

  1. (a)Draw the flow chart of the design cycle of a pattern recognition system, and explain each step in one line. (5 pts)
  2. (b)Explain the difference between supervised and unsupervised learning, and between statistical and structural pattern recognition. (5 pts)

(a) Draw (slide 21)

  • Data collection: is the set of examples "adequately large and representative" for training and testing?
  • Feature choice: depends on the problem domain. Features should be "simple to extract, invariant to irrelevant transformation, insensitive to noise".
  • Model choice: if performance is unsatisfactory, "jump to another class of model".
  • Training: "use data to determine the classifier".
  • Evaluation: "measure the error rate (or performance)" and switch features or model if needed.
  • Computational complexity: the "trade-off between computational ease and performance", and how the algorithm scales with the number of features, patterns or categories.

(b) What to write

Meaning (slide wording)Example
Supervised learning"A teacher provides a category label or cost for each pattern in the training set"fish samples labelled salmon / sea bass
Unsupervised learning"The system forms clusters or natural groupings of the input patterns" (no labels)group unlabelled fish by length and lightness

Structural PR"The data is converted to a discrete structure (such as a grammar or a graph)"; techniques are "parsing and graph matching"a character described by its strokes and how they connect
Exam line

Design cycle: collect data → choose features → choose model → train classifier → evaluate classifier, with feedback from evaluation and prior knowledge into features and model. Supervised: "a teacher provides a category label". Unsupervised: "the system forms clusters". Statistical: "vectors of numbers". Structural: "a discrete structure (such as a grammar or a graph)".

Question 5 · 10 pts · Lecture 4, LZW

Compression: LZW

  1. (a)Encode the string ABBABBBABBAB with LZW. The initial dictionary is A = 1, B = 2. Show the table (s, c, output, code, string) and give the output code sequence. (6 pts)
  2. (b)Decode the LZW code sequence 2 2 1 4 6 1 with the same initial dictionary (A = 1, B = 2). Show the dictionary as it is built and give the decoded string. (4 pts)

(a) Worked solution

  • LZW uses fixed-length codes for variable-length strings. The dictionary is built while encoding, so it is never sent.
s = next char
while not EOF {
    c = next char
    if s + c in dict:  s = s + c
    else {  output code(s);  add s + c;  s = c  }
}
output code(s)

Result: output 1 2 2 3 4 6 3, 12 characters in 7 codes (ratio 12/7 = 1.71 in symbols). Final dictionary: 3 AB, 4 BB, 5 BA, 6 ABB, 7 BBA, 8 ABBA.

(b) Worked solution

  • Each step outputs the entry for code k and adds s + entry[0], where s is the previous entry.
  • If k is not in the dictionary yet, use entry = s + s[0] (Algorithm 7.4). This happens when the encoder used a code in the same step it created it.

Result: decoded string BBABABABA (9 characters). Check: encoding BBABABABA gives 2 2 1 4 6 1 again.

Exam line

LZW: output code(s) when s + c is not in the dictionary, add s + c, set s = c. The decoder adds s + entry[0]. If a code is not in the dictionary yet, entry = s + s[0].

Question 6 · 10 pts · Lecture 3, SNR and SQNR

Audio quality: SNR and SQNR

  1. (a)A signal has a voltage of 5 V and the noise voltage is 0.25 V. Compute the SNR in dB. A second system has a signal power of 2 W and a noise power of 0.5 mW; compute its SNR in dB. Why is the factor 20 in the first case and 10 in the second? (4 pts)
  2. (b)Using SQNR = 6.02N dB: (6 pts)
    1. What is the SQNR of a 12-bit quantizer?
    2. What is the minimum number of bits per sample for an SQNR of at least 50 dB? How many quantization levels does that give?
    3. With that number of bits and an input range of 0 to 2 V, what are the quantization step and the maximum quantization error?

(a) Worked solution

  • SNR = "the ratio of the power of the correct signal to the noise", in dB.
  • Why 20 and 10: "the power in a signal is proportional to the square of the voltage", so 10 log10(Vs² / Vn²) = 20 log10(Vs / Vn). Use 10 log for power ratios and 20 log for voltage ratios.
voltages: SNR = 20 log10(5 / 0.25)     = 20 log10(20)   = 26.02 dB
powers:   SNR = 10 log10(2 / 0.0005)   = 10 log10(4000) = 36.02 dB

Result: 26.02 dB and 36.02 dB.

(b) Worked solution

  • SQNR = 20 log10(2N−1 / ½) = 20N log102 = 6.02N dB, about 6 dB per bit. The quantization error is at most half of the interval.
1. 12 bits: 6.02 × 12 = 72.24 dB
2. 6.02N ≥ 50  →  N ≥ 50 / 6.02 = 8.31  →  N = 9 bits
   (8 bits give 48.16 dB, 9 bits give 54.18 dB);  levels 2⁹ = 512
3. step = 2 V / 512 = 0.0039 V = 3.91 mV
   max error = step / 2 = 0.00195 V = 1.95 mV

Result: 72.24 dB; N = 9 bits, 512 levels; step 3.91 mV, max error 1.95 mV.

Exam line

SNR = 10 log10(Ps/Pn) = 20 log10(Vs/Vn), because power is proportional to voltage squared. SQNR = 6.02N dB, about 6 dB per bit, and the quantization error is at most half a step.

  3. (c)For each pair, say whether the two pixels are 4-adjacent, 8-adjacent and m-adjacent, and justify the m-adjacency answers: (i) (2,2) and (2,3); (ii) (1,1) and (2,2); (iii) (3,1) and (4,2); (iv) (2,3) and (2,4). (4 pts)

  • N4(p) = {(x+1,y), (x−1,y), (x,y+1), (x,y−1)} = {(2,3), (0,3), (1,4), (1,2)}
  • ND(p) = {(x+1,y+1), (x+1,y−1), (x−1,y+1), (x−1,y−1)} = {(2,4), (2,2), (0,4), (0,2)}
  • N8(p) = N4(p) ∪ ND(p) = all 8 pixels above. Neighbours depend only on coordinates, not on values.

D4 = |x − s| + |y − t|        = 3 + 2       = 5
D8 = max(|x − s|, |y − t|)    = max(3, 2)   = 3
De = √(3² + 2²) = √13                       = 3.61
check: D8 ≤ De ≤ D4

Question 8 · 10 pts · Lecture 7, CIE XYZ color

Color: CIE XYZ and chromaticity

  1. (a)Why did the CIE define the XYZ color system instead of using CIE-RGB directly? What are chromaticity coordinates? (4 pts)
  2. (b)Two colors have tristimulus values C1 = (X, Y, Z) = (48, 42, 30) and C2 = (19, 20, 25). Compute the chromaticity coordinates x, y, z of each color. Which color is closer to the D65 white point (x, y) = (0.3127, 0.3290)? Which color is brighter? (6 pts)

(a) What to write

  • CIE-RGB (monochromatic primaries 700, 546.1, 435.8 nm) has a color matching function r̄(λ) that goes negative, so some colors need a negative amount of a primary.
  • In 1931 the CIE defined XYZ, a linear transformation of CIE-RGB, so that XYZ tristimulus values can describe any visible color.
  • Criteria: the CMFs are non-negative (3 positive values for any color); equal amounts give white; ȳ matches the eye's luminous efficiency, so Y = luminance; the primaries are as tight as possible around the visible colors.
  • Chromaticity coordinates: x = X / (X + Y + Z), y = Y / (X + Y + Z), z = Z / (X + Y + Z), with x + y + z = 1. Only (x, y) is plotted, in the chromaticity diagram.
  • Chromaticity specifies the quality of a color (hue and saturation) "regardless of its luminance".

(b) Worked solution

distance to D65:  d = √((x − 0.3127)² + (y − 0.3290)²)

C1 = (48, 42, 30):  X + Y + Z = 120
    x = 48/120 = 0.4000    y = 42/120 = 0.3500    z = 30/120 = 0.2500
    d = √(0.0873² + 0.0210²) = 0.0898
C2 = (19, 20, 25):  X + Y + Z = 64
    x = 19/64 = 0.2969     y = 20/64 = 0.3125     z = 25/64 = 0.3906
    d = √(0.0158² + 0.0165²) = 0.0229
  • C2 is closer to D65 white (0.023 vs 0.090). It is an almost neutral, slightly bluish white. C1 has a large x, so it is shifted towards red/orange.
  • C1 is brighter (Y = 42 vs Y = 20). Brightness is Y, which chromaticity ignores. A dim color can still be near white.

Result: C1 (0.4000, 0.3500, 0.2500), C2 (0.2969, 0.3125, 0.3906); C2 is closer to white, C1 is brighter.

Exam line

CIE-RGB needs negative amounts (r̄ < 0), so the CIE defined XYZ: non-negative CMFs, equal amounts give white, Y = luminance. Chromaticity x = X/(X+Y+Z), y = Y/(X+Y+Z), z = 1 − x − y gives hue and saturation "regardless of its luminance".
