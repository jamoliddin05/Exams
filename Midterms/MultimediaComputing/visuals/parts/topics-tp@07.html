Pixel Relationships and Color from Zero

An image is a grid of numbers. The first half of this lecture asks how pixels relate to each other: who is a neighbor, when two pixels are connected, and how far apart they are. The second half asks what color is: how light becomes three numbers X, Y, Z, and how two ratios x and y place a color on the CIE chromaticity diagram. It builds on Lecture 6's pixel grid and the eye.

Words you need

Pixel f(x, y)

One picture element, the value at row x and column y. The origin (0, 0) is the top-left; x runs down, y runs right.

V

The set of gray values allowed to connect pixels. In a binary image V = {1}.

N4, ND, N8

The 4 pixels sharing an edge with p, the 4 sharing only a corner, and all 8 together.

Adjacent (4, 8, m)

Two pixels with values in V that are neighbors under the chosen rule. m (mixed) drops a diagonal link when a shared 4-neighbor already joins them.

Path, length n

A chain of distinct pixels, each adjacent to the one before. n is the number of steps.

D4, D8, De

City-block |Δx| + |Δy|, chessboard max(|Δx|, |Δy|), Euclidean √(Δx² + Δy²). Unit: pixels.

Wavelength λ

Which pure spectral color a light is, in nanometres (nm). The CIE experiments used 400 to 700 nm.

Tristimulus X, Y, Z

Three non-negative numbers that describe any visible color. Y is the luminance (brightness).

Chromaticity x, y

x = X/(X+Y+Z), y = Y/(X+Y+Z). The color's quality with the brightness divided out.

Reference white, purity

A chosen white point (C, D65, E). Dominant wavelength names the hue; purity, 0 to 1, says how far the color is from white.

1. Where a pixel lives: coordinates and storage (slides 3–4)

  • Origin (0, 0) at the top-left. x is the row (0 … M−1, going down) and y is the column (0 … N−1, going right). School graphs do it the other way round.
  • "An image's element-wise representation treats each pixel independently as an individual data point, whereas its matrix representation structures the entire grid of pixels as a unified mathematical object."
  • Memory is one long line, so the grid is flattened: "for performance reasons we usually do not store image in the matrix fashion ... in Embedded Systems." Matlab is column-major (Lecture 8).

2. Light as energy, light as seen (slides 5–9)

  • Radiometry: light is "a traveling form of energy", unit joule (J). It measures radiation of all optical wavelengths; power is in watts (W). A source has a position, a direction and a wavelength λ. The smallest unit of light is a photon.
  • Frequency does not change when light enters another medium (its speed cₙ and λ do). A photon carries a fixed energy q.
  • Photometry is "measurement of light in terms of visual response it produces": the visible spectrum weighted by the eye. It is a branch of radiometry.
  • Photopic (day) vision peaks at 555 nm (yellow-green) and drops to half at 510 and 610 nm. Scotopic (night) vision peaks at 507 nm (blue-green) and works at lower intensities.

f = cₙ / λ q = h·c / λ (h = 6.626 × 10⁻³⁴ J·s, c = 3 × 10⁸ m/s)

λ = 555 nm = 555 × 10⁻⁹ m
f = 3 × 10⁸ / 555 × 10⁻⁹ = 5.41 × 10¹⁴ Hz
q = 6.626 × 10⁻³⁴ × 3 × 10⁸ / 555 × 10⁻⁹ = 3.58 × 10⁻¹⁹ J

3. Color, gray, and three words for amount of light (slides 10–17)

  • Color is a photometric quantity and a signal (a ripe banana, a red dawn sky). An object's color is the light it reflects. Balanced reflection at all visible wavelengths looks white; reflection favoring a limited range gives chromatic light.
  • Achromatic light is "void of color". Its only attribute is intensity, and achromatic images are gray scale images. Slide 12 calls it "monochromatic (achromatic)", but on slide 67 monochromatic means a single wavelength.
  • The principal energy source for images is the electromagnetic (EM) spectrum; synthetic images are made by computer. The two tasks are better pictures for human interpretation, and image data for storage, transmission and autonomous machine perception.

4. The image as a light function, and its size (slides 18–20)

  • An image is a 2D light-intensity function f(x, y). Light is energy, so 0 < f(x, y) < ∞.
  • f has two parts: illumination i(x, y), the source light falling on the scene, and reflectance r(x, y), the light the objects reflect. f = i · r with 0 < r < 1 (textbook context, Lecture 6).
  • Resolution depends on the sampling M × N and the gray levels. Storage is B = M × N × k bits with L = 2k levels. The slide writes K "gray scale level"; in this formula it must be the bits per pixel k (textbook context).
1024 × 1024, k = 8:  B = 8,388,608 bits = 1,048,576 bytes,  L = 2⁸ = 256
 512 ×  512, k = 8:  B = 2,097,152 bits =   262,144 bytes

6. Connectivity: 4, 8 and m (slides 22–24, 26)

  • V is "the set of gray-level values used to define connectivity". Both pixels must have values in V, whatever the rule.
  • 4-connectivity: q is in N4(p). 8-connectivity: q is in N8(p) (slide 22 prints N4(p) here, a copy-paste typo).
  • "A pixel p is adjacent to a pixel q if they are connected" (slide 26).
  • 8-connectivity can join the same two pixels in two ways, directly and around a corner. "m-connectivity eliminates the multiple path connections that arises in 8-connectivity" (slide 24).

p, q (values in V) are m-connected if (1) q ∈ N₄(p), or (2) q ∈ N_D(p) and N₄(p) ∩ N₄(q) has no pixel whose value is in V

diagonal pair p = (0,2), q = (1,1), V = {1}:
N₄(p) ∩ N₄(q) = {(0,1), (1,2)}  = the other two corners of their 2 × 2 square
values 1 and 0  →  (0,1) is in V  →  NOT m-adjacent (p already reaches q through (0,1))

diagonal pair p = (1,4), q = (2,3):
N₄(p) ∩ N₄(q) = {(1,3), (2,4)},  values 0 and 0  →  none in V  →  m-adjacent

7. Paths, adjacent regions and boundaries (slides 25, 27–29)

  • A digital path from p = (x, y) to q = (s, t) is "a sequence of distinct pixels" (x₀, y₀), …, (xₙ, yₙ), each adjacent to the one before. "n is the length of the path", the number of steps: a path through 5 pixels has n = 4. It is a 4-, 8- or m-path by the adjacency used (textbook context).
  • "Two image area subsets R1 and R2 are adjacent if some pixels in R1 is adjacent to some pixels R2." In the slide 27 figure the only link is one diagonal pair, so the regions are adjacent under 8-adjacency and not under 4-adjacency.
  • A region pixel is a boundary pixel if it is adjacent to the background (textbook context). Slide 28: the circled pixel has four 4-neighbors equal to 1 and one diagonal 0, so "the circle point is part of the boundary ... only if 8-adjacency ... is used".
  • Slide 29, a one-pixel-wide line: "The inner boundary of the 1-valued region does not form a closed path, but its outer boundary does." The line's own pixels run down and stop; the ring of background around it comes back to its start.

8. Distance measures (slides 30–33)

10. Arithmetic and logic on whole images (slides 35–36)

  • "Image arithmetic involves images are same size", and works pixel by pixel: s = f + g, d = f − g, p = f × g, v = f ÷ g, each at (x, y).
  • 8-bit results leave 0 … 255 and are clipped (textbook context, more in Lecture 9).
  • Logic (slide 36): "Black represent binary 0 and white represent binary 1", foreground is white. NOT(A), A AND B, A OR B, A AND [NOT B], A XOR B. AND keeps the overlap, OR the union, XOR the union without the overlap, A AND NOT B removes B from A.

11. Color: hue, value, saturation and Munsell (slides 37–41, 66)

  • A color image has a separate channel per color (RGB). Some models, such as HSI, separate the color information from the brightness.
  • Munsell (1915): "equal perceptual steps in Hue Saturation Value". 10 principal hues R, YR, Y, GY, G, BG, B, PB, P, RP, each split into 10. Value 0 … 10 (dark to pure white), Chroma 0 … 20 (neutral to saturated). 5YR 8/4 reads hue 5YR, value 8, chroma 4 (textbook context).
  • Three qualities of color (slide 39): hue (what color?), value (lightness or darkness), intensity/saturation (its level). A 2D color wheel shows hue and brightness; a 3D color solid adds saturation (slide 40).
  • Slide 66 as a double cone: white at the top, black at the bottom, brightness up the axis, hue is the angle, saturation the distance from the axis (pink to bright red).
  • Representations (slide 41): CIE XYZ, CIE chromaticity space, HSL, HSV, LUV, CIE Lab (L* lightness; a*, b* for red, green, blue, yellow).
  • "Chromaticity is an objective specification of the quality of a color regardless of its luminance": two parameters, hue and colorfulness (saturation, chroma, intensity or excitation purity).

12. CIE XYZ: three positive numbers for any color (slides 42–47, 50–53)

  • Trichromatic theory: "every color can be represented by 3 values", so visible colors form a 3D space. In 1931 the CIE defined XYZ tristimulus values that "can describe any visible color", based on color matching experiments.
  • Matching (textbook context): an observer sees a test light of one wavelength next to a mix of three fixed primaries and turns the three amounts until both look the same. The amounts against λ are the color matching functions (CMFs).
  • CIE-RGB: Wright (1928–30) and Guild (1931), 17 observers, a 2° field, test lights 400–700 nm, primaries 700 nm (R), 546.1 nm (G), 435.8 nm (B).
  • Between about 440 and 540 nm no positive mix matches; red has to be added to the test side, which counts as negative. So r̄(λ) goes negative. XYZ is "a linear transformation away from the observed data" that removes this.

  • Slide 46: the luminous efficiency peaks near 555 nm. Protanopia shifts the peak to about 540 nm with almost no sensitivity above 670 nm; deuteranopia shifts it slightly, to about 560 nm.
  • Slide 53: z̄ peaks about 1.78 near 445 nm, ȳ is 1.0 at 555 nm, x̄ peaks about 1.06 near 600 nm with a small lobe near 445 nm. None goes below 0.

14. The chromaticity diagram: color without brightness (slides 54–60)

Dividing each tristimulus value by the total keeps the proportions and throws away the overall amount, so a dim and a bright version of one color land on the same point.

x = X / (X+Y+Z) y = Y / (X+Y+Z) z = Z / (X+Y+Z) x + y + z = 1

X = 25, Y = 50, Z = 25:   X + Y + Z = 100
x = 25/100 = 0.25,  y = 50/100 = 0.50,  z = 25/100 = 0.25     check 0.25 + 0.50 + 0.25 = 1
doubled (50, 100, 50): sum 200, same x, y, z; only Y = brightness doubled
back from (x, y, Y) (textbook context):  X = (x / y)·Y,  Z = ((1 − x − y) / y)·Y
  • Only (x, y) is plotted; z = 1 − x − y. The horseshoe edge is the spectral locus, labeled in nm; the straight bottom edge is the line of purples (textbook context). White is in the middle (slide 56).
  • Around the locus the hue changes; towards white the saturation drops (slide 60).
  • Gamut (slide 59) is "a certain complete subset of colors", usually what a color space or device can show: the triangle of its primaries. A positive mix of three primaries always lands inside their triangle.
  • Two exam comparisons: closer to white = smaller √((x − xw)² + (y − yw)²); brighter = larger Y.

15. Dominant wavelength and purity: chromaticity in polar coordinates (slides 61–65)

Stand at the reference white W and look at the color S. The direction you look in names the hue; how far S is, compared with the edge of the horseshoe, names the saturation. All three quantities are defined "given a reference white".

Complementary wavelength (p.62)wavelength of the spectral color which, added to the given color, produces the reference white
Purity (p.63)(length from white to the color) / (length from white to the dominant-wavelength point), 0 … 1

W = (0.31, 0.32), S = (0.45, 0.32): the ray goes straight right
it meets the spectral locus at D ≈ (0.68, 0.32), about 615 nm  → dominant wavelength ≈ 615 nm

  • Slide 64 (white = illuminant C): the complementary wavelength of S₁ lies on the opposite side of C. S₂ has no complementary wavelength, because its backward ray hits the line of purples. D₃ lies on the line of purples, and purity is still CS₃ / CD₃.
  • Slide 65: dominant (or complementary) wavelength ≈ hue, the angle around white; purity ≈ saturation, the distance from white.

Mistakes that cost marks

  • Swapping x and y. In this lecture x is the row (down) and y the column (right): (3, 5) is row 3, column 5.
  • Mixing up N4 and ND. N4 changes one coordinate by 1 (edge); ND changes both (corner). N8 is both, 8 pixels.
  • Treating m-adjacency as "8 without diagonals". It keeps a diagonal when N4(p) ∩ N4(q) has no pixel in V. And every kind of adjacency needs both values in V.
  • Counting pixels for the path length. n counts steps: 5 pixels, n = 4.
  • Summing for D8 or taking the max for D4. D4 adds, D8 takes the larger difference. Check D8 ≤ De ≤ D4.
  • Dividing by X + Y or by 100 for chromaticity. Divide by X + Y + Z; the three shares add to exactly 1.
  • Reading brightness from (x, y). Chromaticity ignores luminance; brightness is Y. A dim color can sit right on white.
  • Purity upside down. Purity = |WS| / |WD|, from white towards the locus: 0 at white, 1 on the locus.

Exam focus
  • N4(p) = (x±1, y), (x, y±1); ND(p) = (x±1, y±1); N8 = both. p = (4, 7): N4 = (5,7), (3,7), (4,8), (4,6).
  • m-adjacent: q ∈ N4(p), or q ∈ ND(p) and N4(p) ∩ N4(q) has no value in V. Purpose: "eliminates the multiple path connections" of 8-connectivity.
  • p = (3, 1), q = (7, 4): D4 = 7, D8 = 4, De = 5. D4 ≤ 2 is a 13-pixel diamond, D8 ≤ 2 a 25-pixel square.
  • Path length n = number of steps. Slide 34 m-distance: 2, 3, 4 as p3 and then p1 become 1; the 8-distance stays 2.
  • Photopic peak 555 nm (half at 510, 610), scotopic 507 nm. Radiance W, luminance lm, brightness subjective. 555 nm: f = 5.41 × 10¹⁴ Hz, q = 3.58 × 10⁻¹⁹ J.
  • B = M × N × k: 512 × 512 × 8 = 2,097,152 bits = 262,144 bytes, L = 256.
  • CIE-RGB primaries 700, 546.1, 435.8 nm; 17 observers; 2°; r̄ negative → XYZ (1931). Y = luminance, X = red mix, Z = blue response.
  • x = X/(X+Y+Z), y = Y/(X+Y+Z), z = 1 − x − y. (25, 50, 25) → (0.25, 0.50, 0.25). CIE-RGB R = G = B → E (1/3, 1/3).
  • Illuminants A tungsten, B sunset, C blue sky, D65 daylight (0.3127, 0.3290), E equal energy. PAL: D65, 625 lines; NTSC: C, 525 lines.
  • Purity = |WS| / |WD|: W (0.31, 0.32), S (0.45, 0.32), D (0.68, 0.32) → 0.14 / 0.37 = 0.38, about 615 nm.
  • Munsell value 0–10, chroma 0–20, 10 hues. Monochromatic = one wavelength; achromatic = equal at all wavelengths.
