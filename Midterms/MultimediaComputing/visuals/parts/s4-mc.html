Question 1 · Lecture 2, Bit rate

An audio signal is sampled at 11.025 kHz with 16 bits per sample, in stereo. What is its uncompressed bit rate?

  1. a 176.4 kbps No. 11,025 × 16 = 176,400 bps is one channel. Stereo has two.
  2. b 44.1 kbps No. 352,800 ÷ 8 = 44,100 is the rate in bytes per second (44.1 kB/s).
  3. c 352.8 kbps Correct. 11,025 × 16 × 2 = 352,800 bps.
  4. d 705.6 kbps No. That is 44,100 × 16, the mono CD rate. 11.025 kHz is a quarter of 44.1 kHz.

Answer: c. Bit rate is the number of bits produced per second: sampling rate × quantization bits per sample, times the number of channels. Stereo has two channels, and each one sends its own 16-bit sample at every sampling instant. So 11,025 × 16 × 2 = 352,800 bits/s = 352.8 kbps.

Exam line

Bit rate = sampling rate × quantization bits per sample, in bits per second; multiply by the number of channels. Stereo is twice the mono rate.

Question 2 · Lecture 3, Coding of audio and PCM

Which is the correct order of the blocks in a PCM speech encoder?

  1. a μ-law compressor → bandlimiting filter → linear PCM → transmission No. The bandlimiting filter comes first, before the compressor.
  2. b bandlimiting filter → linear PCM → μ-law expander → transmission No. The expander is a decoder block. It undoes the compressor at the receiver.
  3. c low-pass filter → digital-to-analog converter → μ-law expander → transmission No. Low-pass filter, DAC and expander are all decoder blocks.
  4. d bandlimiting filter → μ-law compressor → linear PCM → transmission Correct. This is the encoder row of Fig. 6.15 (L3 p.44).

Answer: d. Fig. 6.15 on slide 44 has an encoder row and a decoder row. The encoder takes the analog speech through a bandlimiting filter, a μ-law or A-law compressor and linear PCM, then transmits. The decoder runs a digital-to-analog converter, a μ-law or A-law expander and a low-pass filter. Options b and c use decoder blocks, and option a compresses before it filters.

Exam line

PCM encoder: bandlimiting filter → μ-law or A-law compressor → linear PCM → transmission. Decoder: digital-to-analog converter → μ-law or A-law expander → low-pass filter.

Question 3 · Lecture 4, Run length coding

Run-length coding compresses well because it:

  1. a exploits memory in the source: symbols tend to form continuous groups (runs) Correct. Slide 14: RLC exploits memory in the source.
  2. b assumes a memoryless source, where each symbol is independent of the previous ones No. A memoryless source has short runs, and RLE then makes the data longer.
  3. c gives shorter codewords to more probable symbols, using a tree built bottom-up No. That is Huffman coding.
  4. d builds a dictionary of repeated strings while it scans the input No. That is LZW (pattern substitution).

Answer: a. In a memoryless source every symbol is drawn independently of the previous ones. RLC is built for a source with memory, where symbols tend to form continuous groups. It codes each group as two entities, count then symbol, so a run of 8 E's costs only 8E. A lone symbol still costs two entries, like the 1D on slide 15, so a source without runs gets longer.

Question 4 · Lecture 5, MPEG-4 audio, AAC and MP4

What is MP4 (MPEG-4 Part 14)?

  1. a The audio codec that succeeded MP3, based on pure MDCT No. That describes AAC, the audio codec of MPEG-4.
  2. b A multimedia container (wrapper) format that stores video and audio streams and metadata Correct. Slide 52: MPEG-4 Part 14, extension .mp4, a container format.
  3. c MPEG-1 Audio Layer III No. MPEG-1 Audio Layer III is MP3, an audio codec.
  4. d A lossless audio format, like FLAC No. FLAC is a lossless audio coding format. MP4 codes no audio itself; it stores streams that codecs made.

Answer: b. MPEG-4 Part 14 (.mp4) is a multimedia container (wrapper) format. It stores digital video and audio streams and allows Internet streaming. Slide 52 calls it a meta-file format whose spec describes how different data elements and metadata coexist in a computer file. AAC, MP3 and FLAC are codings of the audio itself, one layer below the container.

Exam line

MPEG-4 Part 14 = MP4 (.mp4): a multimedia container (wrapper) format that stores digital video and audio streams and allows Internet streaming. AAC is the codec that succeeded MP3.

Question 5 · Lecture 6, Representing and storing a digital image

How many bits are needed to store a 512 x 512 gray-scale image with 64 gray levels?

  1. a 1,572,864 bits Correct. k = log₂ 64 = 6, so 512 × 512 × 6.
  2. b 2,097,152 bits No. That is 512 × 512 × 8, for 256 gray levels.
  3. c 16,777,216 bits No. That multiplies by L = 64 in place of k = 6.
  4. d 196,608 bits No. That is the answer in bytes, 1,572,864 ÷ 8.

Answer: a. An image with L gray levels needs k bits per pixel, where L = 2k. Here 64 = 2⁶, so k = 6. The number of bits is b = M × N × k = 512 × 512 × 6 = 262,144 pixels × 6 bits = 1,572,864 bits.

Exam line

L = 2k gray levels, 0 ≤ f(x, y) ≤ L − 1. Bits to store an M × N image: b = M × N × k (b = N²k for a square image).

Question 6 · Lecture 7, CIE XYZ color coordinate system

In the CIE XYZ color system, which tristimulus value represents luminance (perceived brightness)?

  1. a X No. X is the "red mix", chosen mathematically to keep the values positive.
  2. b Z No. Z is the "blue response" to short wavelengths.
  3. c Y Correct. Slide 47: Y = luminance (perceived brightness).
  4. d x = X / (X + Y + Z) No. x is a chromaticity coordinate. Dividing by X + Y + Z removes the brightness.

Answer: c. The CIE defined the matching function ȳ(λ) to match the luminous-efficiency function of the eye (criterion 3, slide 45). Y is built with ȳ, so Y measures luminance, the perceived brightness (slide 47). X is the "red mix" and Z the "blue response". The chromaticity x is a ratio, and a ratio stays the same when the light gets brighter or dimmer.

Exam line

Y = luminance (perceived brightness), X = "red mix", Z = "blue response". ȳ is defined to match the luminous-efficiency function of the eye.

Question 7 · Lecture 9, Arithmetic operations

Adding the constant 40 to every pixel of an 8-bit image (with clamping at 255) mainly:

  1. a increases the contrast; the histogram is stretched No. Stretching needs multiplication. Adding moves every level by the same amount.
  2. b increases the brightness; the histogram shifts right and the contrast does not change Correct. Slides 46-48: adding and subtracting adjust brightness and cannot adjust the contrast.
  3. c flattens the histogram, as histogram equalization does No. Equalization maps each level through the CDF, a different move for each level.
  4. d inverts the image, as the NOT operation does No. NOT maps r to 255 − r and reverses the order of the levels.

Answer: b. Adding a constant maps every gray level r to r + 40, the same shift for every pixel. The whole histogram moves 40 levels to the right, so the image gets brighter. The gaps between gray levels stay the same, so the contrast does not change (slide 48: adding and subtracting cannot adjust the contrast). Clamping only touches pixels that would pass 255.

Exam line

Addition and subtraction adjust brightness; division and multiplication adjust contrast. Adding and subtracting cannot adjust the contrast. Overflow is clamped: below 0 becomes 0, above 255 becomes 255.

Question 8 · Lecture 10, Erosion

Which morphological operation makes foreground (bright) regions shrink and the holes inside them grow?

  1. a Dilation No. Dilation grows the foreground and fills small holes.
  2. b Closing No. Closing (dilation, then erosion) fills small holes and keeps the outline.
  3. c Region filling No. Region filling fills a hole from a seed point inside it.
  4. d Erosion Correct. Erode, shrink, reduce (L10 p.15).

Answer: d. Erosion writes the local minimum under the structuring element to each pixel (slide 18). With a 3 × 3 square of 1s, a foreground pixel survives only if its whole window is foreground. Pixels on the outer boundary touch the background and become 0, and so do the pixels around a hole. The region shrinks and the hole grows. Dilation, the local maximum, does the opposite.

Exam line

Erosion (erode, shrink, reduce): areas of foreground pixels shrink in size, and holes within those areas become larger. It is the local minimum over the kernel; dilation is the local maximum.

Source: L10 p.15 erosion: foreground shrinks, holes grow · L10 p.18 erosion = local minimum · Notes: Lecture 10 › Erosion

Question 9 · Lecture 11, Blurring

The 3x3 Gaussian smoothing mask is written as (1/16) x [1 2 1; 2 4 2; 1 2 1]. Why the factor 1/16?

  1. a The mask window contains 16 pixels No. A 3 × 3 window holds 9 pixels.
  2. b It makes the weights sum to 0, so flat regions become 0 No. A sum of 0 belongs to a high-pass mask such as the Laplacian. This mask sums to 1.
  3. c 16 is the sum of the weights, so the mask sums to 1 and a flat region keeps its value Correct. 1 + 2 + 1 + 2 + 4 + 2 + 1 + 2 + 1 = 16.
  4. d It equals 1/σ² for σ = 4 No. 1/16 happens to equal 1/4². The factor comes from the weight sum, and these weights fit σ ≈ 0.85.

Answer: c. A blurring mask should not change the overall brightness. The weights add up to 1 + 2 + 1 + 2 + 4 + 2 + 1 + 2 + 1 = 16, so the factor 1/16 makes the mask sum to 1. On a flat region of value v the output is 16v / 16 = v. Written out, the slide's mask is [1/16 1/8 1/16; 1/8 1/4 1/8; 1/16 1/8 1/16].

Exam line

Gaussian 3 × 3 mask = (1/16)[1 2 1; 2 4 2; 1 2 1]: the weights sum to 16, so the mask sums to 1 and a flat region keeps its value. The center gets the largest weight, 4/16.

Question 10 · Lecture 12, Pattern recognition system flowchart

In a pattern recognition system, which stage should produce features that are invariant to translation, rotation and scale?

  1. a Feature extraction Correct. Slide 19: "Invariant features with respect to translation, rotation and scale."
  2. b Sensing No. Sensing is the transducer (camera or microphone) that captures the input.
  3. c Segmentation and grouping No. Segmentation makes the patterns well separated so they do not overlap.
  4. d Post-processing No. Post-processing exploits context to improve the decision.

Answer: a. The feature extractor turns each segmented object into the feature vector that the classifier uses. Slide 19 asks for discriminative features that are invariant with respect to translation, rotation and scale. Then the same fish gets the same feature values wherever it lies, however it is turned and however large it appears in the image.

Exam line

Feature extraction: discriminative features; invariant features with respect to translation, rotation and scale. Order: sensing → segmentation → feature extraction → classification → post-processing → decision.
