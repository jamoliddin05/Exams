Arithmetic Coding and MPEG Audio from Zero

Lecture 4 coded symbols one at a time without losing anything. This lecture first finishes lossless coding with arithmetic coding, which turns a whole message into one number. Then it lets data go: lossy compression, how the ear hides quiet sounds behind loud ones (masking), and how MPEG audio (MP2, MP3, AAC) spends bits only where you can hear them.

Words you need

Interval [low, high)

All numbers x with low ≤ x < high. It contains low but not high. Its width is range = high − low. Arithmetic coding writes a whole message as one such interval inside [0, 1).

Terminator $

A special end-of-message symbol. The decoder stops when it reads it. Slide 5 labels it G, and slides 6, 7 and 10 write it as $.

Binary fraction

0.b₁b₂b₃… = b₁/2 + b₂/4 + b₃/8 + … So 0.01₂ = 0.25 and 0.101₂ = 0.625. The arithmetic codeword is a binary fraction.

Lossless and lossy

Lossless: the decoder gets the original back exactly (Huffman, LZW, arithmetic coding, PNG, FLAC). Lossy: "a close approximation" with a much higher compression ratio (JPEG, MP3, AAC).

Quantization

Rounding every value to one of a small set of levels. Many inputs give the same output, so it cannot be undone. It is the "main source of the loss".

Rate R and distortion D

Rate: bits per symbol (or kbps for audio). Distortion: how far the decoded data is from the original, for example the fraction of wrong symbols or the mean squared error.

Decibel, dB

A log scale for sound level. +20 dB is 10 × the amplitude and +6 dB is about 2 ×. 0 dB is about the quietest tone a person can hear, near 2 kHz.

Masking

A loud sound makes a weaker sound near it in frequency or in time inaudible. MPEG audio removes "sounds which are masked anyway".

Sub-band

One slice of the frequency range. The MPEG audio filter bank cuts the sound into 32 equal sub-bands, and each one gets its own number of bits.

SNR, SMR, MNR

Signal-to-noise, signal-to-mask and mask-to-noise ratio, all in dB. MNR = SNR − SMR. A positive MNR means the coding noise is hidden under the mask.

1. Arithmetic coding: one interval for the whole message (slides 2–3)

Huffman coding (Lecture 4) "assigns each symbol a codeword which has an integral bit length". A symbol with probability 0.3 carries log₂(1/0.3) = 1.74 bits of information, but its codeword must be 1 bit or 2 bits. The rounding to whole bits happens on every symbol, and the waste adds up.

  • Arithmetic coding "is a more modern coding method that usually out-performs Huffman coding". It "can treat the whole message as one unit".
  • "A message is represented by a half-open interval [a, b) where a and b are real numbers between 0 and 1. Initially, the interval is [0, 1)."
  • "When the message becomes longer, the length of the interval shortens and the number of bits needed to represent the interval increases."
  • Think of decimals. In 0.37 the digit 3 picks the 4th tenth of [0, 1), and the 7 picks a tenth of that tenth. Arithmetic coding cuts the interval into unequal slices instead, one per symbol, as wide as the symbol's probability. A likely symbol gets a wide slice, and a wide slice costs few bits.

width of the final interval = p(s₁) × p(s₂) × … × p(sₙ) bits needed ≈ log₂(1 / width)

message CAEE$ with the slide-5 table (next section)
width       = 0.2 × 0.2 × 0.3 × 0.3 × 0.1 = 0.00036
information = log₂(1 / 0.00036)            = 11.44 bits

Huffman for the same table: average 2.6 bits per symbol (entropy 2.55)
  E → 2 bits, C and A → 2 and 3 bits, $ → 3 bits:  CAEE$ = 12 bits
arithmetic codeword for CAEE$ (section 3): 0.01010101₂ = 8 bits

3. The codeword: the shortest binary fraction inside (slide 8)

Any number in [0.33184, 0.3322) identifies CAEE$. "The final step in Arithmetic encoding calls for the generation of a number that falls within the range [low, high)." The encoder sends the one with the fewest bits.

PROCEDURE 7.2  Generating Codeword for Encoder
code = 0;  k = 1;
while (value(code) < low) {
    assign 1 to the kth binary fraction bit
    if (value(code) > high)  replace the kth bit by 0
    k = k + 1;
}
  • In words: try a 1 in the next bit. If the value goes above high, put a 0 there instead. Stop as soon as the value reaches low.
  • Bit k is worth 2−k: 0.5, 0.25, 0.125, 0.0625, … So each bit halves the window where the code can still land. It is a binary search for the interval.
  • "The above algorithm will ensure that the shortest binary codeword is found."

4. The decoder, and keeping the numbers small (slides 9–10)

The decoder has the same table. It turns the codeword back into a number and asks: in which symbol's slice does this number lie? Then it zooms into that slice and asks again.

ALGORITHM 7.6  Arithmetic Coding Decoder
value = value(code);
do {
    find a symbol s so that  Range_low(s) <= value < Range_high(s);
    output s;
    value = (value - Range_low(s)) / (Range_high(s) - Range_low(s));
} until s is the terminator

value′ = (value − Range_low(s)) / p(s) stop after the terminator $

  • Why the terminator matters: one more step would give (0.953125 − 0.9) / 0.1 = 0.53125, which lies in D's slice. Without $ the decoder could not know where the message ends.
  • Slide 10's first cell wraps as "0.3320312 / 5". It is 0.33203125, the codeword of section 3.
  • Scaling and incremental coding is listed on slide 2, and no slide explains it (textbook context). The interval keeps shrinking, so the numbers need more and more digits. The fix is to send bits as soon as they are certain and then double the interval.
  • (textbook context) If [low, high) lies in [0, 0.5), send 0 and map x → 2x. If it lies in [0.5, 1), send 1 and map x → 2x − 1. After C, [0.3, 0.5) is in the lower half: send 0, giving [0.6, 1.0). That is in the upper half: send 1, giving [0.2, 1.0). The codeword 01010101 indeed starts with 01.

5. Lossy compression and the rate–distortion trade-off (slides 11–12)

  • Lossy compression: "The compressed data is not the same as the original data but a close approximation of it." It "yields a much higher compression ratio than that of lossless compression."
  • Rate-distortion theory "provides a framework for the study of tradeoffs between Rate and Distortion". The more distortion you accept, the fewer bits you need.
  • Slide 12 (Fig. 8.1) draws the typical curve R(D). At D = 0 (no loss) R(D) = H, the entropy, which is the lossless limit of Lecture 4. R(D) falls as D grows and reaches 0 at D = Dmax.
  • So a lossless coder is stuck at D = 0 and can never go below H bits per symbol. A lossy coder accepts some D > 0 and moves down the curve.
(textbook context) a source of 0s and 1s with 20% 1s; D = fraction of symbols decoded wrong
R(D) = H(0.2) − H(D),  H(p) = −p log₂ p − (1 − p) log₂(1 − p)
D = 0     R = 0.722 bits per symbol   the entropy, the lossless limit
D = 0.05  R = 0.436                   5% wrong buys a 2.3 : 1 ratio against 1 bit
D = 0.2   R = 0                       Dmax: send nothing, always guess 0
  • (textbook context) For audio and images the usual distortion is the mean squared error, MSE = (1/N) Σ (xₙ − yₙ)², or PSNR = 10 log₁₀(xpeak² / MSE) dB.

6. Quantization: where the loss happens (slide 13)

  • Quantization: "Reduce the number of output values to a much smaller set." It is the "main source of the loss in lossy compression".
  • Why: it is many-to-one. With a step of 10, the inputs 58, 61 and 64 all leave as 60. A decoder that receives 60 cannot know which one it was.
  • The other stages of a compressor (Lecture 4, slide 6: transformation, loss, coding) are one-to-one. A prediction can be undone, and Huffman or arithmetic coding gives back exactly what went in.
  • "Uniform: The type of quantization in which the quantization levels are uniformly spaced."
  • "Nonuniform: in which the quantization levels are unequal and mostly the relation between them is logarithmic." Small values get fine steps and large values coarse steps, like the μ-law compander of Lecture 3.

7. How the ear hears: threshold of hearing and frequency masking (slides 14–16)

MPEG audio throws away what the ear cannot hear. Two facts about hearing decide what that is.

  • Threshold of hearing (slides 15–16, Fig. 14.2): a tone is heard only if its level is above the curve. The curve depends on frequency. Turning a tone up until it reaches the curve makes it just audible.

Threshold(f) = 3.64 (f/1000)−0.8 − 6.5 e−0.6 (f/1000 − 3.3)² + 10−3 (f/1000)4 dB (Eq. 14.1, f in Hz)

f          100 Hz    1 kHz    2 kHz    3.3 kHz   10 kHz
threshold  22.95     3.37     −0.25    −4.98     10.58    dB
                              ≈ 0: the curve is pinned to 0 dB at 2 kHz
                                       lowest point: the ear is most sensitive here
  • Frequency masking (slide 14): a loud tone raises the threshold around its own frequency, so weaker tones nearby disappear. Lossy audio methods such as MPEG/Audio "remove some sounds which are masked anyway". The four rules:
  • 1. "A lower tone can effectively mask a higher tone."
  • 2. "The reverse is not true": a higher tone does not mask a lower tone well.
  • 3. "The greater the power of the masking tone, the wider is its influence", a broader range of masked frequencies.
  • 4. So "if two tones are widely separated in frequency then little masking occurs".

10. The MPEG audio encoder: four blocks (slides 29–31)

  • Filter bank (slide 31): it "divides input into multiple sub-bands (32 equal frequency sub-bands)". This is the move from the time domain to the frequency domain.
  • (textbook context) The sampled sound reaches up to fs/2, so each sub-band is (fs/2)/32 wide: 500 Hz at 32 kHz, 689 Hz at 44.1 kHz, 750 Hz at 48 kHz.
  • Slide 30's figure is titled "Aliasing: pure sinusoid input can produce nonzero output for two subbands". Neighbouring filters overlap, so a tone near a band edge shows up in both bands.
  • Quantization and bit/noise allocation: "If noise level is high => rough quantization; if noise level is low => finer quantization is applied." Section 12 shows how the bits are shared.
  • Multiplexer and entropy coder: Huffman coding (Lecture 4) of the quantized values, packed into the compressed bitstream.

11. The psychoacoustic model: what the ear cannot hear (slides 32–36)

  • The psychoacoustic model "compresses by removing acoustically irrelevant parts of audio signals". It "takes advantage of human auditory systems inability to hear quantization noise under auditory masking".
  • Auditory masking "occurs whenever the presence of a strong audio signal makes a temporal or spectral neighborhood of weaker audio signals imperceptible". Spectral means near in frequency, temporal means near in time.
  • Loudness and pitch (slide 34): we are "more sensitive to loudness at mid frequencies", [500 Hz, 5000 Hz]. Human hearing covers [20 Hz, 20000 Hz]. The basilar membrane in the inner ear "reacts more to intermediate frequencies".
  • Slide 33's hearing curve (15.6 Hz to 16 kHz) shows the same shape as Eq. 14.1: about 80 dB needed at 15.6 Hz, about 0 dB near 1 kHz, a dip below 0 near 4 kHz, rising again above 8 kHz.
  • Slide 35, frequency masking curves for maskers at 0.25, 1, 4 and 8 kHz (60 dB): the higher the masker, the wider its curve, and every curve reaches further up than down.
  • Slide 35, temporal masking: a loud sound also hides weak sounds just before it starts and for a while after it stops. Pre-masking lasts about 20 ms, simultaneous masking lasts while the masker plays (about 200 ms in the figure), post-masking about 150 ms.
  • Slide 36: "MPEG/audio divides audio signal into frequency sub-bands that approximate critical bands. Then we quantize each sub-band according to the audibility of quantization noise within the band."
  • (textbook context) A critical band is the frequency range the ear treats as one channel: about 100 Hz wide below 500 Hz and about 20% of the frequency above that. Noise inside a critical band is masked by a strong tone in the same band.

12. Bit allocation: give bits where the noise would be heard (slide 37)

Bit allocation "determines number of code bits allocated to each sub-band based on information from the psycho-acoustic model". The ratios are in dB:

  • SNR, signal-to-noise: how far the quantization noise is below the signal. It grows with the bits: "for each added bit, we get 6dB better SNR ratio" (slide 41).
  • SMR, signal-to-mask: how far the mask (the masked threshold) is below the signal. It comes from the psychoacoustic model (textbook context).
  • MNR, mask-to-noise: MNR = SNR − SMR. With S, M and N the levels of signal, mask and noise, SNR = S − N and SMR = S − M, so MNR = M − N: how far the noise sits under the mask. MNR > 0 means the noise is inaudible.
Algorithm (slide 37)
1. compute the mask-to-noise ratio MNR = SNR − SMR
   ("standard provides tables that give estimates for SNR resulting from
   quantizing to a given number of quantizer levels")
2. get MNR for each sub-band
3. search for the sub-band with the lowest MNR
4. allocate code bits to this sub-band; if it gets more code bits than
   appropriate, look up a new estimate of SNR and repeat step 1

  • Sub-band 4's signal is already under its mask (SMR < 0), so it is inaudible and gets no bits at all.
  • The rule always helps the worst band first. The loudest band does not win because it is loud. It wins because its noise is the furthest above its mask.

13. Audio quality, the MP3 file, and why fewer bits is compression (slides 38–41)

  • Bitrate (slide 38): "with too low bit rate, we get compression artifacts". Ringing, and pre-echo: "sound is heard before it occurs", "most noticeable in impulsive sounds from percussion instruments such as cymbals". Pre-echo "occurs in transform-based audio compression algorithms".
  • Quality also depends on the encoder and its parameters: constant bit rate (CBR) or variable bit rate (VBR) encoding. (textbook context) CBR spends the same kbps on every frame. VBR spends more on complex passages and less on simple ones.
  • MP3 (slide 39): "A psychoacoustic model refers to an analysis of an audio signal that determines the amount of noise masking available based on frequency and loudness." It eliminates sounds humans cannot hear and focuses the bits on the most important frequencies.
  • MP3 file (slide 40): a sequence of frames, each an MP3 header plus MP3 data, usually after an ID3 tag with metadata. The 32-bit header of the example is FFFBA040:

15. MPEG-4 Audio, AAC and MP4 (slides 47–53)

  • AAC, Advanced Audio Coding, is the successor of MP3 and "now part of MPEG-4 Audio". Up to 48 full-bandwidth audio channels. Default audio format for iPhone, iPad, Nintendo, PlayStation, Nokia, Android, BlackBerry.
  • AAC was "introduced 1997 as MPEG-2 Part 7". "In 1999 – updated and included in MPEG-4".
  • AAC's improvements over MP3 (slide 49): more sample frequencies (8–96 kHz); arbitrary bit rates and variable frame length; higher efficiency and a simpler filterbank; it "uses pure MDCT". Also used in Windows Media Audio.
  • MPEG-4 Audio (slide 48): bit rate 2–64 kbps, scalable for variable rates. It defines a set of coders:

Mistakes that cost marks

  • Computing high from the new low. After C that gives [0.3, 0.8). Both ends come from the old low: [0.3, 0.5).
  • Forgetting the range check. The final range must equal the product of the probabilities (CAEE$: 0.00036). If it does not, a row is wrong.
  • Codeword: keeping a 1 that pushes the value above high, or stopping before the value reaches low. Stop exactly when low ≤ value. Write the bits and the decimal value, and show low ≤ code < high.
  • Decoder: dividing by the old interval's range. Divide by the found symbol's own width p(s), and stop after the terminator.
  • Calling arithmetic coding lossy. It is lossless. Quantization is the main source of loss, not Huffman, run-length coding or the transform.
  • Masking direction. A lower tone masks a higher tone, not the reverse. A louder masker masks a wider range. Tones far apart barely mask each other.
  • Bit allocation: the next bit goes to the lowest MNR, with MNR = SNR − SMR. Not the highest SMR and not the loudest band.
  • MPEG names. MP3 = MPEG-1 Layer 3, target 64 kbps (32–320 kbps). AAC is the codec (MPEG-2 Part 7). MP4 = MPEG-4 Part 14 is a container, not a codec. 1.4 Mbit/s is bits, 176,400 bytes per second.

Cheat sheet

How to write it on the exam

ARITHMETIC CODING (encode + codeword, about 7 pts)
1. table: symbol, p, [Range_low, Range_high)   (running sums of p)
2. rule:  low' = low + range × Range_low(s),  high' = low + range × Range_high(s),
          both from the OLD low;  range' = high' − low'
3. one row per symbol (start 0, 1, 1): low, high, range, with the products written
4. final interval [low, high);  check range = p₁ × p₂ × … × pₙ
5. codeword (Procedure 7.2): for k = 1, 2, …  try bit k = 1; if value > high → 0;
   stop when value ≥ low.  Answer: bits, decimal value, low ≤ code < high
6. optional check: decode it.  s with Range_low ≤ v < Range_high,  v ← (v − Range_low) / p(s)

LOSSY vs LOSSLESS (about 3 pts)
definition: lossless = no information loss, exact copy; lossy = close approximation
lossy gives a much higher compression ratio; quantization is the main source of loss
examples: lossless PNG, FLAC, Huffman, LZW;  lossy JPEG, MP3, AAC
why lossy beats the entropy: R(D) = H at D = 0, and R(D) < H once D > 0

MASKING (about 3 pts)
auditory masking: a strong signal makes weaker signals near it in time or frequency inaudible
frequency: lower masks higher; not the reverse; louder → wider; far apart → little
temporal: pre ≈ 20 ms, simultaneous while the masker plays, post ≈ 150 ms

MPEG AUDIO ENCODER (about 3 pts)
draw: audio → filter bank (32 equal sub-bands, time → frequency)
           → psychoacoustic model (masking → SMR)      both feed
      quantization, bit/noise allocation → multiplexer, entropy coder (Huffman) → bitstream
one line per block

BIT ALLOCATION (about 4 pts)
MNR = SNR − SMR for every sub-band; a table with one row per round
lowest MNR gets the bit → its SNR + 6 dB → recompute → repeat
answer: bits per sub-band and the final MNRs
Exam focus
  • Arithmetic beats Huffman because Huffman needs an integral number of bits per symbol, while arithmetic coding codes the whole message as one interval [a, b).
  • Encoding CAEE$: [0.3, 0.5), [0.3, 0.34), [0.322, 0.334), [0.3286, 0.3322), [0.33184, 0.3322); range 0.00036 = 0.2 × 0.2 × 0.3 × 0.3 × 0.1.
  • EC$: [0.55, 0.85) → [0.64, 0.7) → [0.694, 0.7), range 0.006. Codeword 0.1011001₂ = 0.6953125 (7 bits).
  • CAEE$ codeword 0.01010101₂ = 0.33203125 (8 bits). Decoding gives 0.16015625, 0.80078125, 0.8359375, 0.953125 → CAEE$.
  • Lossy = close approximation, much higher ratio; quantization is the main source of loss; uniform vs nonuniform (logarithmic) levels; R(D) = H at D = 0 and 0 at Dmax.
  • Threshold of hearing: about 0 dB at 2 kHz, 3.37 dB at 1 kHz, lowest (−5 dB) near 3.3 kHz; most sensitive 500–5000 Hz; hearing 20–20000 Hz.
  • Masking rules: lower masks higher, not the reverse, louder masks wider, far apart masks little. Temporal: pre ≈ 20 ms, post ≈ 150 ms.
  • CD audio 44100 × 16 × 2 = 1,411,200 bit/s; at 128 kbps that is 11.025 : 1.
  • MPEG-1 Audio: 16 bits; 32, 44.1, 48 kHz; Layer 1 32–448 (192), Layer 2 = MP2 32–384 (128), Layer 3 = MP3 32–320 (64) kbps.
  • Encoder: filter bank (32 equal sub-bands) + psychoacoustic model → quantization and bit allocation → Huffman. MNR = SNR − SMR, next bit to the lowest MNR; 1 bit ≈ 6 dB.
  • AAC: MPEG-2 Part 7 (1997), MPEG-4 (1999), pure MDCT, 8–96 kHz, 48 channels. MP4 = MPEG-4 Part 14, a container format.
