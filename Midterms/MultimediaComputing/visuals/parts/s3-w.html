Question 1 · 10 pts · Lecture 10, Morphology

Morphology: opening

  1. (a)What is morphological opening? Write its formula and state what it removes from a binary image. (4 pts)
  2. (b)Apply opening to the 7x7 binary image A using the 3x3 structuring element B. Show the intermediate result and the final result. Rows and columns are numbered 0-6 from the top-left; pixels outside the image are 0. (6 pts)

(a) What to write

  • Opening "is obtained by the erosion of an image followed by a dilation", both with the same SE B.
  • A ∘ B = (A ⊖ B) ⊕ B = ∪{(B)z | (B)z ⊆ A}, the union of all translates of B that fit inside A.
  • The erosion removes foreground pixels from the edges of regions. The dilation restores the size of everything that survived.
  • "Opening can remove small bright spots and connect small dark cracks." It smooths the contour of an object, "breaks narrow isthmuses, and eliminates thin protrusions".
  • Anything B cannot fit into disappears: isolated noise pixels, 1-pixel-wide lines.

(b) Step 1: erosion A ⊖ B

  • A pixel stays 1 only if the whole 3x3 window around it is 1, so B fits there. Outside the image counts as 0.
  • (2,2), (2,3), (3,2), (3,3): window all 1, so 1.
  • (2,4): its window has (1,5) = 0 and (3,5) = 0, so 0.
  • (1,1): the top row of its window is row 0, all 0, so 0. Every other edge pixel of the block fails the same way.
  • Protrusion (2,5), (2,6) and noise pixel (5,6): their windows contain 0s, so 0.

(b) Step 2: dilation of A ⊖ B by B

  • A pixel becomes 1 if its 3x3 window hits at least one 1 of A ⊖ B.
  • So each of the 4 surviving pixels grows back into a 3x3 square. Their union is rows 1-4, cols 1-4.
  • Pixel count: 19 in A, 4 after erosion, 16 after opening. A ∘ B ⊆ A, as it must be.

Result: A ∘ B is the 4x4 block at rows 1-4, cols 1-4, restored exactly. The protrusion (2,5), (2,6) and the isolated noise pixel (5,6) are removed.

Exam line

Opening = erosion followed by dilation, A ∘ B = (A ⊖ B) ⊕ B. It removes small bright spots, breaks narrow isthmuses and eliminates thin protrusions, and keeps the shape of everything B fits into.

Question 2 · 10 pts · Lecture 11, Spatial filtering

Order-statistic filters: median, max, min

  1. (a)Explain how the median, max and min filters work. Which one removes salt (white, 255) noise, which removes pepper (black, 0) noise, and which one handles both? (4 pts)
  2. (b)The 5x5 image I below has salt and pepper noise. Apply a 3x3 median, max and min filter at pixel P1 = (1,1) and at pixel P2 = (2,3) (row, column; (0,0) is the top-left). For each pixel give the sorted window and the three outputs, and comment on the results. (6 pts)

(a) What to write

  • All three are nonlinear filters. Sort the pixels of the 3x3 window and replace the centre pixel by one of them.
  • Median = the middle value, the 5th of 9. "An effective method for removing impulse noise" that preserves "sharp edges ... and detail". It removes both salt and pepper.
  • Min = the smallest value. "Min filter: removes white spikes; overall intensity will be reduced." White spikes are salt.
  • Max = the largest value. "Max: removes dark spikes; overall intensity is increased." Dark spikes are pepper.
  • "Both the min and max filters fail in removing mixed impulse noises." Only a cascade of max and min filters, or the median, removes salt and pepper together.

(b) Worked solution

P1 = (1,1) and P2 = (2,3) are interior pixels, so no border rule is needed.

P1 (1,1): 50 52 55 / 51 255 57 / 53 56 58
  sorted 50 51 52 53 [55] 56 57 58 255
  median 55   max 255   min 50
P2 (2,3): 57 60 62 / 58 0 64 / 61 63 255
  sorted 0 57 58 60 [61] 62 63 64 255
  median 61   max 255   min 0
  • P1's window has only salt. Min removes it (50, slightly darker than its neighbours), max keeps the 255, and the median 55 is clean.
  • P2's window has pepper at the centre and salt at the corner (3,4). Max gives 255 and min gives 0, so both fail on mixed noise. The median 61 is clean.
  • A 3x3 mean would give 76.33 and 75.56, with the noise smeared into the output.

Result: P1: median 55, max 255, min 50. P2: median 61, max 255, min 0. Only the median removes the mixed salt and pepper noise.

Exam line

Median removes impulse (salt and pepper) noise and keeps edges. Min removes white spikes (salt), max removes dark spikes (pepper), and both fail on mixed impulse noise.

Histogram specification

A 3-bit image A (L = 8, 4x4 pixels) and a desired histogram are given.

  3. (c)Build the look-up table z = G⁻¹(T(r)). (3 pts)

Method

  • Histogram specification "requires both a desired histogram and the image as input".
  • (1) Equalize the original image, s = T(r). (2) Equalize the desired histogram, v = G(z). (3) Apply the inverse transform, z = G⁻¹(s) = G⁻¹[T(r)].
  • Normalized sum = cumulative count × (L − 1)/N² = cumulative × 7/16. s is rounded to the nearest integer. G(z) is kept unrounded, and each s goes to the z whose G(z) is closest (equal G values: smallest z).

(b) G(z) of the desired histogram

(c) Inverse look-up table

  • s = 1: |1 − 0| = 1 and |1 − 1.3125| = 0.3125, so z = 3.
  • s = 4: |4 − 3.0625| = 0.9375 < |4 − 5.25| = 1.25, so z = 4.
  • s = 2 and s = 4 never occur in A, so the rule "smallest z with G(z) ≥ s" gives the same output here.

Result: LUT r → z: 1→3, 2→4, 3→5, 4→6, 5→7 (unused: 0→0, 6→7, 7→7).

Question 4 · 10 pts · Lecture 12, Pattern recognition

Pattern recognition: flow chart and nearest class mean

  1. (a)Draw the flow chart of a pattern recognition system from input to decision, including the side inputs, and state in one line what each stage does. (5 pts)
  2. (b)Fish on a conveyor are described by the feature vector x = [lightness, width]. Training samples are given below. Use the nearest class mean classifier with Euclidean distance. A fish is put in the reject class if its distance to the nearest mean is greater than 4. Compute the two class means and classify x1 = [6, 18] and x2 = [11, 15]. (5 pts)

(a) Flow chart (slide 18, read bottom to top)

  • Sensing: "Use of a transducer (camera or microphone)".
  • Segmentation (and grouping): "Patterns should be well separated and should not overlap".
  • Feature extraction: "Discriminative features"; "Invariant features with respect to translation, rotation and scale".
  • Classification: "Use a feature vector provided by a feature extractor to assign the object to a category".
  • Post-processing: "Exploit context input dependent information other than from the target pattern itself to improve performance".
  • Side inputs: costs → post-processing; adjustments for context → classification and post-processing; adjustments for missing features → classification.

(b) Nearest class mean

  • Rule (slide 38): compute the Euclidean distance from x to each class mean. Choose the closest class if it is close enough, otherwise reject.
salmon mean   = [(3+4+5)/3, (15+17+16)/3] = [4, 16]
sea bass mean = [(7+9+8)/3, (20+21+22)/3] = [8, 21]

x1 = [6, 18]:  d(salmon)   = √((6−4)² + (18−16)²) = √8  = 2.83
               d(sea bass) = √((6−8)² + (18−21)²) = √13 = 3.61
               nearest salmon, 2.83 ≤ 4  → salmon
x2 = [11, 15]: d(salmon)   = √(7² + 1²) = √50 = 7.07
               d(sea bass) = √(3² + 6²) = √45 = 6.71
               nearest sea bass, 6.71 > 4 → reject class

Result: means [4, 16] and [8, 21]; x1 → salmon (2.83); x2 → reject class (nearest 6.71 > 4).

Exam line

Input → sensing → segmentation → feature extraction → classification → post-processing → decision, with costs and context adjustments as side inputs. Nearest class mean: assign x to the closest mean if it is close enough, otherwise reject.

Question 5 · 10 pts · Lectures 4-5, Compression

Compression: lossy vs lossless, arithmetic coding

  1. (a)What is the difference between lossless and lossy compression? Classify JPEG, PNG and MP3. (3 pts)
  2. (b)Encode the message BAB$ ($ is the terminator) with arithmetic coding using the table below. Show low, high and range after each symbol, give the final interval, and generate the shortest binary codeword inside it. (7 pts)

(a) What to write

  • "If the compression and decompression processes induce no information loss, then the compression scheme is lossless; otherwise, it is lossy."
  • Lossless: the decoded data equals the original exactly, at a lower compression ratio. Examples: PNG (images), FLAC and Apple Lossless (audio, "at the cost of larger files"), Huffman, LZW, RLE.
  • Lossy: "The compressed data is not the same as the original data but a close approximation of it", with "a much higher compression ratio". Quantization is the main source of the loss. Examples: JPEG (images), MP3 and AAC (audio, perceptual coding).
  • JPEG → lossy, PNG → lossless, MP3 → lossy.

(b) Encoding BAB$

  • Both bounds use the old low: low′ = low + range × Rlow(s), high′ = low + range × Rhigh(s), range′ = high′ − low′.

Final interval [0.4804, 0.484). Check: range = 0.3 × 0.4 × 0.3 × 0.1 = 0.0036.

(b) Codeword (Procedure 7.2)

  • For k = 1, 2, ... set bit k to 1. If the value exceeds high, set it back to 0. Stop as soon as value ≥ low.

Result: codeword 0.01111011₂ = 0.48046875, 8 bits, and 0.4804 ≤ 0.48046875 < 0.484.

decode 0.48046875 → B   (0.48046875 − 0.4)/0.3 = 0.2682
       0.2682     → A   0.2682/0.4             = 0.6706
       0.6706     → B   (0.6706 − 0.4)/0.3     = 0.9019
       0.9019     → $   stop
Exam line

Lossless: no information loss, the original comes back exactly (PNG, FLAC). Lossy: a close approximation with a much higher compression ratio (JPEG, MP3). Arithmetic coding narrows [low, high) by each symbol's range, both bounds from the old low.

Question 6 · 10 pts · Lecture 5, Psychoacoustics and MPEG audio

Psychoacoustics and MPEG audio

  1. (a)Explain frequency masking and temporal masking. (3 pts)
  2. (b)Draw the block diagram of the MPEG audio (MP3) encoder and say what each block does. (3 pts)
  3. (c)Bit allocation. Three sub-bands have the following SNR and SMR (in dB). Compute MNR = SNR - SMR for each sub-band and say which sub-band gets the next bit. Then allocate 3 bits one at a time, assuming each bit raises that sub-band's SNR by 6 dB. Give the final MNR of each sub-band. (4 pts)

(a) What to write

  • Auditory masking "occurs whenever the presence of a strong audio signal makes a temporal or spectral neighborhood of weaker audio signals imperceptible." MPEG audio removes "sounds which are masked anyway".
  • Frequency masking: a loud tone hides weaker tones at nearby frequencies. (1) A lower tone can effectively mask a higher tone. (2) The reverse is not true: a higher tone does not mask a lower tone well. (3) The greater the power of the masking tone, the wider its influence. (4) So two tones widely separated in frequency show little masking.
  • Temporal masking: a loud sound hides weaker sounds close to it in time. Pre-masking about 20 ms before the masker, simultaneous masking while it is on (about 200 ms in the figure), post-masking about 150 ms after it.

(b) MPEG audio encoder (slide 29)

  • Filter bank: "divides input into multiple sub-bands (32 equal frequency sub-bands)", time to frequency domain.
  • Psychoacoustic model: "removing acoustically irrelevant parts", using the ear's "inability to hear quantization noise under auditory masking". (Textbook) It gives the SMR of each sub-band.
  • Quantization, bit/noise allocation: "If noise level is high => rough quantization; if noise level is low => finer quantization is applied."
  • Multiplexer / entropy coder: Huffman coding of the quantized values into the bitstream.

(c) Bit allocation

  • Slide 37: compute MNR = SNR − SMR, find the sub-band with the lowest MNR, give it bits, update its SNR, repeat. Each bit adds 6 dB (slide 41).
round        SNR (1, 2, 3)   MNR (1, 2, 3)   lowest MNR
start        28, 22, 35      16,  4, 15      sub-band 2
after bit 1  28, 28, 35      16, 10, 15      sub-band 2
after bit 2  28, 34, 35      16, 16, 15      sub-band 3
after bit 3  28, 34, 41      16, 16, 21      done

Result: the next bit goes to sub-band 2 (MNR 4 dB). After 3 bits: sub-band 2 gets 2 bits, sub-band 3 gets 1, sub-band 1 gets 0; final MNR = 16, 16, 21 dB.

Exam line

A lower tone masks a higher tone, and a louder masker masks a wider range. Temporal masking: about 20 ms before and 150 ms after the masker. Bit allocation: MNR = SNR − SMR, give the next bit to the sub-band with the lowest MNR.

Question 7 · 10 pts · Lecture 6, Image basics and resampling

Image resampling and interpolation

  1. (a)When do we need to resample an image? Compare nearest neighbour, bilinear and bicubic interpolation. (3 pts)
  2. (b)Four neighbouring pixels of an image are given as f(row, col). Find the value at the point (row 2.7, col 4.25) using bilinear interpolation, and using nearest neighbour interpolation. (5 pts)
  3. (c)A 640 x 480 RGB image (24 bits per pixel) is downscaled by 50% in each direction. Give the new size and the storage before and after, in bytes. (2 pts)

(a) What to write

  • We need to resample the image when: rescaling; applying a geometrical transformation; the output image coordinates are not discrete.
  • Nearest neighbour: the 1 closest pixel. "Fast and simple"; "loss of sharpness"; "artifacts (checkerboard)".
  • Bilinear: the 4 nearest pixels, weighted by distance. Smoother than nearest neighbour, medium speed (textbook).
  • Bicubic: the 16 nearest pixels, 4x4 (textbook). "Images are sharpest"; "fine details are preserved"; "slow".

(b) Worked solution

offsets   a = 4.25 − 4 = 0.25 (column),  b = 2.7 − 2 = 0.7 (row)
row 2     40 + 0.25 (80 − 40)  = 50
row 3     60 + 0.25 (120 − 60) = 75
between   50 + 0.7 (75 − 50)   = 67.5
check     0.225·40 + 0.075·80 + 0.525·60 + 0.175·120
          = 9 + 6 + 31.5 + 21  = 67.5

f = (1−a)(1−b) f(2,4) + a(1−b) f(2,5) + (1−a)b f(3,4) + ab f(3,5)

Result: bilinear = 67.5 (68 as an integer pixel); nearest neighbour: row 2.7 → 3, col 4.25 → 4, so f(3,4) = 60.

(c) Storage

new size  640/2 × 480/2 = 320 × 240
b = M × N × k, k = 24 bits = 3 bytes
before    640 × 480 × 3 = 921,600 bytes
after     320 × 240 × 3 = 230,400 bytes  (1/4)

Result: 320 x 240; 921,600 bytes before, 230,400 bytes after.

Exam line

Resample when rescaling, applying a geometrical transformation, or when output coordinates are not discrete. Nearest neighbour is fast and simple with checkerboard artifacts; bicubic gives the sharpest images but is slow. Storage b = M × N × k.

Question 8 · 10 pts · Lectures 6 and 9, Intensity transformations

Intensity transformations

An 8-bit image (L = 256) has the pixel values r = 31, 63, 127 and 200. For each value compute:

  1. (a)the image negative, and give one application of it. (2 pts)
  2. (b)the log transformation s = c log(1 + r) with c = 255 / log(1 + 255). (3 pts)
  3. (c)gamma correction s = 255 (r/255)^γ with γ = 0.5; also compute r = 127 with γ = 2.0. Which values of γ brighten the image? (3 pts)
  4. (d)contrast stretching with low = 50 and high = 150. (2 pts)

(a) and (b) Negative and log

  • "Intensity transformation is a point process that converts an old pixel into a new pixel based on some predefined function", implemented with a LUT.
  • Negative s = 255 − r: 31 → 224, 63 → 192, 127 → 128, 200 → 55. Applications: display of medical images; producing negative prints.
  • Log: c = 255 / log₁₀(256) = 105.89 (with ln, c = 45.99; s is the same in any base). 1 + r = 32, 64, 128 are powers of 2, so s = 255 × log₂(1 + r) / 8.
r = 31    1 + r = 32    255 × 5/8 = 159.375 → 159
r = 63    1 + r = 64    255 × 6/8 = 191.25  → 191
r = 127   1 + r = 128   255 × 7/8 = 223.125 → 223
r = 200   1 + r = 201   105.89 × log₁₀(201) = 105.89 × 2.3032 = 243.88 → 244

(c) Gamma, s = 255 (r/255)^γ (slide 47 convention)

γ = 0.5   31 → 88.91 → 89     63 → 126.75 → 127
          127 → 179.96 → 180  200 → 225.83 → 226
          (slide code, uint8 truncates: 88, 126, 179, 225)
γ = 2.0   127 → 255 (127/255)² = 63.25 → 63 (darker)
  • With this convention γ < 1 brightens and γ > 1 darkens.
  • Slide 49 writes output = input^(1/γ), which reverses this. Say which form you use.

(d) Contrast stretching (slide 37)

output = 0                        for x ≤ low
         255 (x − low)/(high − low) for low < x ≤ high
         255                      for x ≥ high
31  ≤ 50                         → 0
63   255 × 13/100 = 33.15        → 33
127  255 × 77/100 = 196.35       → 196
200 ≥ 150                        → 255

Result: negative 224, 192, 128, 55; log 159, 191, 223, 244; γ = 0.5: 89, 127, 180, 226 (r = 127, γ = 2: 63); stretch 0, 33, 196, 255.

Exam line

Intensity transformation is a point process applied through a LUT. Negative y = −x + 255. Gamma s = 255 (r/255)^γ: γ < 1 brightens, γ > 1 darkens. Contrast stretching: 0 below low, 255 above high, linear in between.
