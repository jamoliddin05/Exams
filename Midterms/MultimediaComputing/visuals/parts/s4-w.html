Question 1 · 10 pts · Lecture 10, Opening and closing

Morphology: closing

  1. (a)What is morphological closing? How does it differ from opening (order of the operations and effect on the image)? (4 pts)
  2. (b)Apply closing to the binary image A with the 3x3 structuring element B (all 1s, origin at the centre, marked in brackets). Show A ⊕ B first, then (A ⊕ B) ⊖ B. Pixels outside the image count as 0. Which pixels of A changed, and why? (6 pts)

(a) Closing against opening

  • Closing is a dilation followed by an erosion: A • B = (A ⊕ B) ⊖ B. "Closing can remove small dark spots and connect small bright cracks." It smooths contours, "fuses narrow breaks and long thin gulfs, eliminates small holes, and fills gaps in the contour". The result contains A: A ⊆ A • B.
  • Opening is an erosion followed by a dilation: A ∘ B = (A ⊖ B) ⊕ B. "Opening can remove small bright spots and connect small dark cracks." It breaks narrow isthmuses and eliminates thin protrusions. The result lies inside A: A ∘ B ⊆ A.
  • Rolling ball picture: opening rolls B along the inside of the boundary of A, closing rolls B along the outside. Both are idempotent, so closing twice gives the same result as closing once.

(b) Step 1: dilation A ⊕ B

  • Dilation with a 3x3 block of 1s is a 3x3 local maximum. A pixel becomes 1 if its window holds at least one 1 of A. Outside the image counts as 0.
  • Only (0,3) and (1,3) stay 0. The window of (1,3) covers rows 0-2, columns 2-4, and all of it is 0. The in-image part of the window of (0,3) is also all 0.
  • Every other pixel becomes 1, including the frame of the image: 47 ones.

(b) Step 2: erosion (A ⊕ B) ⊖ B

  • Erosion is a 3x3 local minimum. A pixel stays 1 only if all 9 pixels of its window are 1.
  • Rows 0 and 6 and columns 0 and 6 become 0, because their windows reach outside the image.
  • (1,2), (1,3), (1,4), (2,2), (2,3), (2,4) become 0, because their windows contain (0,3) or (1,3).
  • Every other interior pixel stays 1.
  • (4,2): the one-pixel hole is filled ("eliminates small holes").
  • (2,5): the break in the right arm is fused ("fuses narrow breaks").
  • (3,4): the one-pixel crack is filled ("fills gaps in the contour").
  • No 1 became 0, so A ⊆ A • B holds. The notch at rows 1-2, columns 2-4 is 3 pixels wide. B fits inside it, so it stays open. Closing only fills gaps smaller than the structuring element.
  • For contrast, opening A with the same B gives an empty image, because no 3x3 block of 1s fits inside A.

Result: 16 ones become 19. Changed pixels: (4,2), (2,5), (3,4), all 0 → 1.

Exam line

Closing = dilation followed by erosion, A • B = (A ⊕ B) ⊖ B. It removes small dark spots, eliminates small holes and fills gaps in the contour, and A ⊆ A • B. Opening = erosion followed by dilation; it removes small bright spots, and A ∘ B ⊆ A.

Question 2 · 10 pts · Lecture 11, Spatial filtering

Filtering: blurring

  1. (a)Name and briefly explain the four ways to treat the image borders when convolving with a 3x3 mask. (4 pts)
  2. (b)8-bit image I (rows and columns numbered from 0, pixel (row, col)). Average mask = (1/9) x [1 1 1; 1 1 1; 1 1 1]. Gaussian mask = (1/16) x [1 2 1; 2 4 2; 1 2 1].
  3. (i)Apply both masks at the interior pixel (2,2). Which result stays closer to the original value, and why? (3 pts)
  4. (ii)Apply both masks at the corner pixel (0,0), once with zero padding and once with duplication of the edges. Which border method gives the more realistic result? (3 pts)

(a) Four border methods (slide 15)

  • Zero padding: treat the empty cells of the window as zeros. Simple, but it darkens the border.
  • Start convolving at the first position where the window does not overlap the image: start at (1,1) instead of (0,0) with a 3x3 mask. The output loses a 1-pixel frame (here 5x5 → 3x3).
  • Duplication of the edges: copy the top row, the left side, the right side and the bottom of the image outward.
  • Wrap-around: the opposite edge supplies the missing neighbours, as if the image were periodic.

(b)(i) Interior pixel (2,2) = 100

  • The Gaussian result stays closer to 100. It gives the centre the weight 4/16 = 0.25, against 1/9 = 0.11 for the average, and the corners only 1/16. So it blurs less.

(b)(ii) Corner pixel (0,0) = 80

(b) Cumulative sum and LUT

Result: LUT r → s: 0→0, 1→1, 2→2, 3→4, 4→6, 5→7, 6→7, 7→7.

(a) Flow chart, bottom to top as on slide 18

  • Order: input → sensing → segmentation → feature extraction → classification → post-processing → decision. Solid arrows carry data up; dotted arrows go down to the stage below.

Compression: Shannon-Fano and run-length coding

  1. (a)A source emitted 32 symbols with these counts:
SymbolABCDE

Build the Shannon-Fano code (top-down splits, left branch = 0, right branch = 1). Give each codeword and the total number of bits, and compare with a fixed-length code. (6 pts)

  1. (b)Run-length encode string X = KKKKKKKMMMNNNNNNNNNPKKKKSSSSSS (count, then symbol) and give the compression ratio in symbols. Then encode string Y = PQRST and comment on the result. (4 pts)

(a) Shannon-Fano

  • Shannon-Fano is a top-down approach: 1. sort the symbols by count; 2. recursively divide them into two parts with approximately the same counts until each part has one symbol. Left = 0, right = 1.
  • Sorted: A 10, B 9, C 6, D 4, E 3 (total 32).

  • Total = 71 bits, average 71/32 = 2.22 bits/symbol.
  • Fixed-length: 5 symbols need ⌈log₂ 5⌉ = 3 bits, so 32 × 3 = 96 bits. Shannon-Fano saves 25 bits; compression ratio B0/B1 = 96/71 = 1.35.
  • Entropy η = Σ pi log₂(1/pi) = 0.5244 + 0.5147 + 0.4528 + 0.3750 + 0.3202 = 2.187 bits/symbol (lower bound 32 × 2.187 = 69.99 bits). Efficiency = 2.187 / 2.219 = 98.6%. Huffman gives the same code lengths here, also 71 bits.

(b) Run-length coding

  • RLE codes each run as count, then symbol.
  • X = KKKKKKK MMM NNNNNNNNN P KKKK SSSSSS has the runs 7K, 3M, 9N, 1P, 4K, 6S, so X → 7K3M9N1P4K6S: 30 symbols → 12 symbols, compression ratio = 30/12 = 2.5.
  • Y → 1P1Q1R1S1T: 5 symbols → 10 symbols, ratio 0.5, so the "compressed" output is twice as long. There are no runs: each single symbol still costs two entries (count + symbol, like the 1D on the slide).
  • RLE only pays off when the source has memory, i.e. symbols form continuous groups.

Shannon-Fano: sort, then recursively split into two parts with about the same counts; left 0, right 1. Here 71 bits against 96 fixed, ratio 1.35. RLE codes count then symbol: X → 7K3M9N1P4K6S (ratio 2.5), Y → 1P1Q1R1S1T (ratio 0.5).

MIDI

  1. (a)What is MIDI? Why is a MIDI file much smaller than a WAV file of the same song? Support your answer by computing the size of 3 minutes of CD-quality WAV audio (44.1 kHz, 16 bits, stereo) and comparing it with about 3 kB of MIDI. (4 pts)

(a) What MIDI is, and why it is small

  • MIDI (Musical Instrument Digital Interface, early 1980s) is a protocol adopted by the electronic music industry. It lets computers, synthesizers, keyboards and other musical devices communicate.
  • MIDI is a scripting language: it codes events (which note, its volume, which instrument), not the sound itself. A WAV file stores every audio sample, so MIDI files are generally very small.

Question 8 · 10 pts · Lecture 11, Edge detection

Edge detection

  1. (a)Compare first-order and second-order derivative edge operators. Then compare the Roberts, Prewitt and Sobel operators. (4 pts)
  2. (b)Two 3x3 neighbourhoods; the pixel of interest is the centre one. Apply a mask by multiplying each pixel by the mask weight in the same position and adding (no flipping).
  3. (i)At the centre of W1 compute H_r, H_c, the gradient magnitude (both the square-root form and the |H_r| + |H_c| form) and the direction θ = tan⁻¹(H_c / H_r). (3 pts)
  4. (ii)Apply the Laplacian at the centre of W1 and of W2. Use the same mask as the point detection mask with threshold T = 400: is a point detected in W1? In W2? (3 pts)

(a) First order against second order

  • First order (gradient based: Roberts, Prewitt, Sobel): one spike per edge. Gives the magnitude H = √(Hr² + Hc²) (or |Hr| + |Hc|) and the direction θ = tan⁻¹(Hc / Hr).
  • Second order (Laplacian; LoG): a +/− pair per edge. The sign change (zero crossing) marks the edge centre, so "better edge localization". But "unacceptably sensitive to noise", "produce double edges", "unable to detect edge direction".
  • Roberts: "smaller effective area than the other masks" (diagonal differences); "more susceptible to noise".
  • Prewitt: weights 1 1 1; "more sensitive to vertical and horizontal edges than diagonal edges".
  • Sobel: weights 1 2 1 (the centre row or column is weighted, which smooths); "more sensitive to diagonal edges than vertical and horizontal edges".

(b)(i) Prewitt gradient at the centre of W1

Hr = left column − right column = (50+70+90) − (10+20+30) = 210 − 60 = 150
Hc = bottom row − top row       = (90+60+30) − (50+30+10) = 180 − 90 = 90
√(150² + 90²) = √(22,500 + 8,100) = √30,600 = 174.93
|150| + |90|  = 240
θ = tan⁻¹(90 / 150) = tan⁻¹(0.6) = 30.96°
  • Intensity falls from left to right and rises downward: a diagonal edge with the bright side at the bottom-left.

(b)(ii) Laplacian and point detection

  • Laplacian / point mask: R = 8 · zcentre − (sum of the 8 neighbours). A point is detected where |R| > T.
  • W1: neighbours 50+30+10+70+20+90+60+30 = 360, R = 8(40) − 360 = −40. |R| = 40 ≤ 400: no, a smooth ramp/edge, not a point.
  • W2: neighbours 30+32+30+28+30+30+30+34 = 244, R = 8(110) − 244 = 636. |R| = 636 > 400: isolated point detected.
  • The Laplacian is small on W1, where the intensity changes almost linearly, so a large first derivative comes with a near-zero second derivative. W2 has one bright pixel on a nearly constant background, so the response is large.
Exam line

First order: one spike, gives magnitude √(Hr² + Hc²) or |Hr| + |Hc| and direction tan⁻¹(Hc / Hr). Laplacian: zero crossing, better localization, but noise sensitive, double edges, no direction. Point detected where |R| > T.
