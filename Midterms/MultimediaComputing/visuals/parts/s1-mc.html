Question 1 · Lecture 2, Sine wave parameters

A 50 Hz sine wave is shifted by a phase of 90 degrees. By how much time is the wave shifted?

  1. a 2.5 ms No. 2.5 ms is T/8, a shift of 45°.
  2. b 5 ms Correct. 90° is a quarter of a cycle, and T/4 = 20 ms / 4 = 5 ms.
  3. c 10 ms No. 10 ms is T/2, a shift of 180°.
  4. d 20 ms No. 20 ms is a full period, 360°. The wave lands back on itself.

Answer: b. The period is T = 1/f = 1/50 s = 20 ms. One full cycle is 360°, so a phase of 90° (π/2 rad) is a quarter of a cycle. The wave moves by a quarter of its period, 20 ms / 4 = 5 ms.

In general the time shift is Δt = (φ / 360°) × T.

Exam line

T = 1/f. A phase of 90° = π/2 rad shifts the wave by T/4, and 180° = π rad shifts it by T/2. For 50 Hz, T = 20 ms, so 90° is 5 ms.

Question 2 · Lecture 2, Sampling theorem and Nyquist

An audio signal contains frequencies up to 12 kHz. What is the Nyquist sampling frequency for this signal (the frequency the sampling rate must be greater than)?

  1. a 6 kHz No. That halves 12 kHz instead of doubling it, the fs/2 mix-up.
  2. b 12 kHz No. That is fmax itself, one sample per cycle.
  3. c 24 kHz Correct. 2 × fmax = 2 × 12 kHz = 24 kHz.
  4. d 48 kHz No. 48 kHz is a safe rate above 24 kHz, but it is 4 × fmax, not the Nyquist sampling frequency.

Answer: c. The signal has to be sampled at a frequency greater than twice the maximal frequency occurring in it, fs > 2 fmax. Here 2 × 12 kHz = 24 kHz.

Slide 48 calls 2 fmax the Nyquist sampling frequency. Its example is a 10 kHz signal that must be sampled above 20 kHz.

Exam line

Sample at a frequency greater than twice the maximal frequency in the signal, fs > 2 fmax. 2 fmax is the Nyquist sampling frequency, so 12 kHz max gives 24 kHz.

Question 3 · Lecture 3, Signal to noise ratio

The signal voltage is 100 times the noise voltage. The SNR is:

  1. a 40 dB Correct. 20 log₁₀(100) = 20 × 2 = 40 dB.
  2. b 20 dB No. That is 10 log₁₀(100), the power form used on a voltage ratio.
  3. c 100 dB No. 100 is the plain voltage ratio, not a value in decibels.
  4. d 2 dB No. 2 is log₁₀(100) without the factor 20.

Answer: a. The power in a signal is proportional to the square of the voltage. A voltage ratio of 100 is a power ratio of 100² = 10,000, and 10 log₁₀(10,000) = 40 dB.

The slide writes this as SNR = 10 log₁₀(V²signal / V²noise) = 20 log₁₀(Vsignal / Vnoise). Use 20 log₁₀ for voltage ratios and 10 log₁₀ for power ratios.

Exam line

SNR = 10 log₁₀(V²signal / V²noise) = 20 log₁₀(Vsignal / Vnoise), because power is proportional to the square of the voltage. 10 log for power ratios, 20 log for voltage ratios. 100 × the voltage is 40 dB.

Question 4 · Lecture 4, Properties of Huffman coding

Which property of Huffman codes makes it possible to decode a bitstream without any ambiguity, with no separators between codewords?

  1. a The two least frequent symbols have codes of the same length No. True for Huffman, but it says nothing about where one codeword ends.
  2. b The average code length is strictly less than the entropy + 1 No. True (η ≤ l̄ < η + 1), but it is a bound on length, not a decoding rule.
  3. c More frequent symbols get shorter codes No. True, but a code can do this and still be ambiguous (Figure 2).
  4. d No codeword is a prefix of any other codeword Correct. The unique prefix property (L4 p.30).

Answer: d. The unique prefix property says no Huffman code is a prefix of any other Huffman code, which "precludes any ambiguity in decoding". Every symbol sits on a leaf of the tree, so the decoder follows bits from the root until it reaches a leaf, outputs that symbol and starts again at the root.

Options a, b and c are the optimality properties from the same slide. They are true for Huffman codes, but none of them decides how to split a bitstream.

Exam line

Unique prefix property: no Huffman code is a prefix of any other Huffman code, which precludes any ambiguity in decoding. Optimality: the two least frequent symbols have the same length, frequent symbols get shorter codes, and η ≤ l̄ < η + 1.

Question 5 · Lecture 5, Arithmetic Coding Basics

Why does arithmetic coding usually outperform Huffman coding?

  1. a It is lossy, so it can drop rarely used symbols No. Arithmetic coding is lossless: the decoder gets the exact message back.
  2. b Huffman gives every symbol a codeword with an integral number of bits, while arithmetic coding treats the whole message as one unit, an interval [a, b) Correct. This is the slide's wording (L5 p.3).
  3. c It builds a dictionary of repeated strings and sends a fixed-length code for each string No. That describes LZW.
  4. d It codes each run of identical symbols as a count followed by the symbol No. That describes run-length coding (RLE).

Answer: b. Huffman coding gives each symbol its own codeword, and a codeword is always a whole number of bits. A symbol that carries only 0.15 bits of information still costs at least 1 bit.

Arithmetic coding has no per-symbol codewords. It narrows one interval [a, b) symbol by symbol and sends a single number from the final interval. The rounding to whole bits happens once for the whole message, not once per symbol, so the output gets close to the entropy.

Count + symbol: RLE

Exam line

Huffman: an integral number of bits per symbol. Arithmetic coding: the whole message is one unit, a half-open interval [a, b) with 0 ≤ a < b ≤ 1. Both are lossless.

Question 6 · Lecture 6, Human eye structure

Which statement about the two receptors in the retina is correct?

  1. a Rods are located in the fovea and are highly sensitive to color No. That describes cones. Rods are insensitive to color.
  2. b Cones dominate scotopic (low illumination) vision, so dim scenes appear black and white No. Scotopic vision uses only rods. Cones need good light.
  3. c Cones are located in the fovea and are highly sensitive to color; rods are insensitive to color but sensitive to low levels of illumination Correct. This is the slide-4 wording.
  4. d Rods dominate photopic vision and provide color No. Photopic vision uses cones, and cones provide the color.

Answer: c. The retina has two receptors. Cones are located in the fovea and are highly sensitive to color. Rods give a general overall picture of the view. They are insensitive to color and sensitive to low levels of illumination.

That fixes the two vision modes. In low light (scotopic vision) only rods work, so objects are visible but appear in black and white. In good light (photopic vision) cones dominate and provide color. Options b and d swap rods and cones.

Exam line

Cones are located in the fovea and are highly sensitive to color. Rods are insensitive to color and sensitive to low levels of illumination. Scotopic vision uses only rods (black and white). Photopic vision uses cones and provides color.

Question 7 · Lecture 7, Distance measures

Two pixels are p = (1, 2) and q = (6, 4). The chessboard distance D8(p, q) is:

  1. a 2 No. 2 is |2 − 4|, the smaller difference. The max takes the larger one.
  2. b 5.39 No. That is the Euclidean distance √(5² + 2²) = √29.
  3. c 7 No. That is D4, the city-block distance 5 + 2.
  4. d 5 Correct. D8 = max(|1 − 6|, |2 − 4|) = max(5, 2) = 5.

Answer: d. The chessboard distance is D8(p, q) = max(|x − s|, |y − t|) for p = (x, y) and q = (s, t). The differences are |1 − 6| = 5 and |2 − 4| = 2, so D8 = 5.

A move to any of the 8 neighbors costs 1, like a king on a chessboard. The 2 columns are covered by diagonal moves while the walk covers the 5 rows, so the larger difference is the whole cost.

Exam line

Chessboard distance D8(p, q) = max(|x − s|, |y − t|), and D8 ≤ r forms a square. City-block D4 = |x − s| + |y − t| forms a diamond. Euclidean De = √((x − s)² + (y − t)²).

Question 8 · Lecture 9, Histogram equalization

The goal of histogram equalization is to:

  1. a obtain a uniform histogram for the output image, by mapping gray level r to s so that s is uniformly distributed Correct. This is the goal on slide 20.
  2. b shift the histogram to the right by adding a constant to every pixel No. Adding a constant brightens the image and slides the histogram, but its shape stays the same.
  3. c make the output histogram match a desired histogram given by the user No. That is histogram specification (slide 40), which needs a desired histogram as a second input.
  4. d reduce the number of gray levels so that the image needs less storage No. Fewer gray levels is requantization (posterizing), not equalization.

Answer: a. Histogram equalization maps each gray level r to s = T(r), where T is the normalized sum of the histogram (the CDF). Gray levels that hold many pixels get spread over a wide output range, and rare levels get squeezed together.

In the continuous case this makes the output density exactly uniform, ps(s) = 1 (slide 24). With discrete gray levels the result is spread over the full range but not perfectly flat (slide 26).

Exam line

Goal of histogram equalization: to obtain a uniform histogram for the output image, by mapping r to s = T(r), the normalized cumulative histogram. Histogram specification instead needs both a desired histogram and the image as input.

Question 9 · Lecture 10, Opening and closing

Morphological opening of image A by structuring element B is:

  1. a a dilation followed by an erosion No. Dilation then erosion is closing, A • B.
  2. b the difference between the dilation and the erosion No. That is the morphological gradient (slide 55).
  3. c an erosion followed by a dilation Correct. A ∘ B = (A ⊖ B) ⊕ B.
  4. d an erosion followed by a second erosion No. Two erosions only shrink the shape further, and nothing grows back.

Answer: c. Opening is "obtained by the erosion of an image followed by a dilation" (slide 26): A ∘ B = (A ⊖ B) ⊕ B. The erosion keeps only the places where B fits inside A. The dilation grows what is left back to its size.

Parts where B never fits, such as small bright spots and thin protrusions, do not come back. Closing uses the reverse order, A • B = (A ⊕ B) ⊖ B, and fills small dark gaps instead.

Exam line

Opening A ∘ B = (A ⊖ B) ⊕ B, an erosion followed by a dilation. It removes small bright spots and thin protrusions. Closing A • B = (A ⊕ B) ⊖ B, a dilation followed by an erosion, removes small dark spots. The gradient is dilation minus erosion.

Question 10 · Lecture 12, Learning and adaptation

In pattern recognition, unsupervised learning means that:

  1. a a teacher provides a category label or cost for each pattern in the training set No. That is supervised learning, word for word.
  2. b the system forms clusters or "natural groupings" of the input patterns Correct. This is the slide-28 definition.
  3. c every pattern is put in the reject class until a teacher labels it No. The reject class is where a classifier puts a pattern it cannot assign to any class.
  4. d each pattern is compared with a stored template of every class No. That is template matching, a way to classify.

Answer: b. In supervised learning a teacher provides a category label or cost for each pattern in the training set. In unsupervised learning there is no teacher. The system only sees the feature vectors and forms clusters, or "natural groupings", of the input patterns by itself.

Why the other options are wrong

Option a
Teacher labels: supervised

Every training pattern comes with its category, so the system learns from labelled examples.

pattern+label "salmon"
Option c
Reject class: a classifier output

A classifier assigns a feature vector to one of the designated classes or to the reject class (slide 31).

feature vector→class 1class 2reject
Option d
Stored templates: template matching

The pattern is compared with one stored template per class and gets the best match. That classifies, it does not learn groups.

Exam line

Supervised learning: a teacher provides a category label or cost for each pattern in the training set. Unsupervised learning: the system forms clusters or "natural groupings" of the input patterns.
