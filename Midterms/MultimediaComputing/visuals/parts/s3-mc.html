Question 1 · Lecture 2, Quantization

A signal with range R = 4 V is quantized with b = 5 bits. How many quantization levels are there, and what is the quantization step?

  1. a 5 levels, step 0.8 V No. 5 is the number of bits b. Five bits can write 2⁵ different codes.
  2. b 10 levels, step 0.4 V No. 10 = 2 × 5. Each bit doubles the level count; it does not add 2 levels.
  3. c 32 levels, step 0.125 V Correct. 2⁵ = 32 levels and δ = 4/32 = 0.125 V.
  4. d 25 levels, step 0.16 V No. 25 = 5². The level count is 2b, not b².

Answer: c. Each sample is stored with b bits, and b bits can write 2b different codes, so there are 2⁵ = 32 levels. The range R is shared evenly among the levels: δ = R/2b = 4/32 = 0.125 V.

All four options split 4 V evenly (levels × step = 4 V in every option). So the step cannot tell them apart. Only the level count does, and it must be 2b.

Exam line

b bits give N = 2b levels, and the quantization step is δ = R/2b.

Question 2 · Lecture 3, SQNR

Using SQNR = 6.02N dB, going from 8-bit to 12-bit audio samples raises the maximum SQNR by about:

  1. a 4 dB No. 4 is the number of added bits. Each bit is worth about 6 dB.
  2. b 12 dB No. 12 dB is only 2 bits' worth (2 × 6.02 dB). Here 4 bits are added.
  3. c 48 dB No. 48.16 dB is the SQNR of 8-bit samples itself, not the gain.
  4. d 24 dB Correct. 4 added bits × 6.02 dB = 24.08 dB.

Answer: d. SQNR = 6.02N grows in a straight line with N, so the gain depends only on the number of added bits: 6.02 × 12 − 6.02 × 8 = 72.24 − 48.16 = 24.08 dB.

Each extra bit halves the quantization step, so the largest error (half a step) is halved too. The signal-to-noise voltage ratio doubles, and 20 log₁₀ 2 = 6.02 dB.

Exam line

SQNR = 20 log₁₀ (2N−1 / ½) = 6.02N dB: each bit adds about 6 dB of resolution, so 16 bits provide a maximum SQNR of 96 dB.

Question 3 · Lecture 4, LZW

LZW starts with the dictionary 1 = A, 2 = B. What is the output for the input string BABAA?

  1. a 2 1 3 1 Correct. B, A, then the new entry BA = 3, then A at the end.
  2. b 2 1 2 1 1 No. One code per character never uses the dictionary. At the third character BA is already code 3.
  3. c 2 1 3 5 No. 5 = BAA is the entry added when BA is sent. What is left after BA is only A = 1.
  4. d 2 1 4 1 No. 4 = AB, but the string matched at that point is BA = 3.

Answer: a. LZW keeps a current string s and grows it while s + c is in the dictionary. When s + c is new, it outputs code(s), adds s + c as the next code, and restarts with s = c.

For BABAA: output 2 (B) and add 3 = BA; output 1 (A) and add 4 = AB; BA is now known, so s grows to BA; BAA is new, so output 3 and add 5 = BAA; at EOF output 1 (A).

Question 4 · Lecture 5, Lossy compression

In lossy compression, the main source of the loss is:

  1. a entropy coding (e.g. Huffman) No. Huffman coding is lossless: each codeword decodes to exactly one symbol.
  2. b quantization Correct. Slide 13: the "main source of the loss in lossy compression".
  3. c the transformation stage (e.g. prediction) No. The transformation is reversible: adding the prediction back gives the same values.
  4. d run-length coding No. Run-length coding is lossless: a count and a symbol rebuild the run exactly.

Answer: b. Quantization will "Reduce the number of output values to a much smaller set". Many input values leave the quantizer as the same level, so the decoder cannot tell which one it was. That is where the information is lost.

The other stages are one-to-one. An inverse transformation and an entropy decoder give back exactly what went in.

Exam line

Quantization: "Reduce the number of output values to a much smaller set." It is the "main source of the loss in lossy compression". Huffman, LZW and run-length coding are lossless.

Source: L5 p.13 quantization is the main source of the loss · Notes: Lecture 5 › 6. Lossy Compression, Rate Distortion and Quantization

Question 5 · Lecture 6, Brightness adaptation

On a background of intensity I = 200, the just noticeable difference is ΔIc = 4. The Weber ratio and its meaning are:

  1. a 0.02, poor brightness discrimination No. The number is right, but a small ratio means good discrimination.
  2. b 50, good brightness discrimination No. 50 = I/ΔIc, the ratio turned upside down.
  3. c 0.02, good brightness discrimination Correct. 4/200 = 0.02, and a small ratio means good discrimination.
  4. d 0.2, poor brightness discrimination No. 0.2 would need ΔIc = 40 on I = 200. The given ratio is ten times smaller.

Answer: c. Weber ratio = ΔIc/I = 4/200 = 0.02. It is the fraction of the background intensity that must be added before the observer sees the change.

Here a 2% change is enough, so the eye notices small changes: good brightness discrimination. A large ratio means the change must be large before it is seen: poor discrimination.

Exam line

Weber ratio = ΔIc/I. A small Weber ratio means good brightness discrimination; a large ratio means poor brightness discrimination.

Question 6 · Lecture 7, CIE chromaticity

A color has tristimulus values X = 30, Y = 45, Z = 75. Its chromaticity coordinates are:

  1. a x = 0.40, y = 0.60 (z is not used) No. It divides by X + Y = 75 and leaves Z out of the sum.
  2. b x = 0.20, y = 0.30, z = 0.50, so x + y + z = 1 Correct. Each value is divided by X + Y + Z = 150.
  3. c x = 0.67, y = 1.00, z = 1.67 No. It divides by Y = 45 (X/Y, Y/Y, Z/Y).
  4. d x = 0.30, y = 0.45, z = 0.75, so x + y + z = 1.5 No. It divides by 100. The coordinates always sum to 1.

Answer: b. Each chromaticity coordinate is one tristimulus value divided by the total X + Y + Z = 150: x = 30/150 = 0.2, y = 45/150 = 0.3, z = 75/150 = 0.5.

They are shares of one total, so x + y + z = 1 always. That is why only (x, y) is plotted on the chromaticity diagram; z = 1 − x − y.

Exam line

x = X/(X+Y+Z), y = Y/(X+Y+Z), z = Z/(X+Y+Z), and x + y + z = 1. Only (x, y) is plotted.

Question 7 · Lecture 9, Histogram specification

In histogram specification, T is the equalization of the input image and G is the equalization of the desired histogram. The output level z for an input level r is:

  1. a z = G⁻¹[T(r)] Correct. Equalize the input with T, then undo the desired histogram's equalization with G⁻¹.
  2. b z = T⁻¹[G(r)] No. T and G swap roles. This would turn an image with the desired histogram into one with the input's histogram.
  3. c z = G[T(r)] No. G takes a z and returns an equalized level. Applied forward it never gives back a z.
  4. d z = T[G⁻¹(r)] No. Wrong order. T is built from the input histogram, so r must go through T first.

Answer: a. T and G are both equalizations, so both lead to the same flat histogram: s = T(r) for the input and v = G(z) for the desired histogram.

Matching the two at the shared equalized level, v = s, and solving for z gives z = G⁻¹(s) = G⁻¹[T(r)]. The input goes forward through T, then backward through G.

Exam line

(1) Equalize the original: s = T(r). (2) Equalize the desired histogram: v = G(z). (3) Apply the inverse: z = G⁻¹(s) = G⁻¹[T(r)].

Question 8 · Lecture 10, Dilation

Which expression is the dilation of A by the structuring element B?

  1. a {z | (B)z ⊆ A} No. B shifted to z must fit inside A. That is erosion.
  2. b (A ⊖ B) ⊕ B No. Erosion followed by dilation is opening.
  3. c {z | (B̂)z ∩ A = ∅} No. No overlap at all: these are the positions outside the dilation.
  4. d {z | (B̂)z ∩ A ≠ ∅} Correct. The reflected B shifted to z overlaps A in at least one element.

Answer: d. Slide 20: dilation is "the set of all displacements, z, such that B̂ and A overlap by at least one element". Reflect B about its origin, shift it to z, and keep z if the shifted copy touches A anywhere.

One shared pixel is enough, so A grows by the shape of B. Erosion asks for the opposite extreme: all of B must fit inside A.

Exam line

A ⊕ B = {z | (B̂)z ∩ A ≠ ∅}: the set of all displacements z such that B̂ and A overlap by at least one element. Dilation expands A.

Question 9 · Lecture 11, Edge operators

According to the lecture, the Sobel operator is:

  1. a more sensitive to vertical and horizontal edges than to diagonal edges No. That is the slide's line for Prewitt.

  3. c a second-order operator that produces double edges No. That describes the Laplacian.

Answer: b. Slide 38 gives one property per operator. Sobel: "More sensitive to diagonal edges than vertical and horizontal edges". Prewitt is the opposite, Roberts has the smallest effective area, and the Laplacian is the second-order operator.

Question 10 · Lecture 12, Pattern recognition system

In the pattern recognition system flow chart, which stage receives "costs" as an input and exploits context (input-dependent information other than from the target pattern itself) to improve performance?

  1. a Segmentation No. Segmentation separates the patterns. No side input enters it.
  2. b Feature extraction No. It computes discriminative, invariant features. No side input enters it.
  3. c Classification No. Classification gets adjustments for context and for missing features, but not costs.
  4. d Post-processing Correct. The costs arrow enters post-processing, and it exploits context.

Answer: d. On the slide-18 flow chart three side inputs arrive from the right. Costs go only to post-processing. Adjustments for context go to post-processing and to classification. Adjustments for missing features go to classification.

Post-processing will "Exploit context input dependent information other than from the target pattern itself to improve performance". It is the last stage before the decision.
